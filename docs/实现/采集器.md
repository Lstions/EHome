## 协议字段 (v2.1)

### Hello (0x01, ESP→SVR) — 8 字段

```c
// v2.0 老固件只发 1-4 字段
// v2.1 新固件发全部 8 字段
frame_encode_string(&enc, 1, device_id);
frame_encode_string(&enc, 2, firmware_version);
frame_encode_string(&enc, 3, model);
frame_encode_varint(&enc, 4, channel_count);
// v2.1 新增 ↓
frame_encode_varint(&enc, 5, config_epoch);          // 从 NVS
frame_encode_bool(&enc, 6, nvs_has_config);          // NVS 是否有
frame_encode_string(&enc, 7, last_manifest);         // NVS manifest_id
frame_encode_string(&enc, 8, "2.1");                 // protocol_version
```

### StatusReport (0x02, ESP→SVR) — 5 字段

```c
frame_encode_varint(&enc, 1, uptime_sec);
frame_encode_string(&enc, 2, status);
frame_encode_varint(&enc, 3, channel_count);
// v2.1 新增 ↓
frame_encode_varint(&enc, 4, config_epoch);          // 同步周期上报
frame_encode_varint(&enc, 5, sync_state);            // idle/syncing/error
```

### ConfigManifest (0x04, SVR→ESP) — 6 字段

```c
frame_encode_string(&enc, 1, manifest_id);
// v2.1 新增 ↓
frame_encode_varint(&enc, 2, config_epoch);          // 服务端当前 epoch
// ... 原有 templates/channels (字段 3/4) ...
frame_encode_string(&enc, 5, sync_id);               // UUID
frame_encode_varint(&enc, 6, sync_reason);           // enum
```

### 新增消息 (v2.1)

- **0x13 ConfigSyncRequest** (ESP→SVR): 主动请求最新 config
- **0x14 ConfigSyncResponse** (SVR→ESP): 同步请求响应

## Kconfig (v2.1 新增)

```kconfig
# 同步周期 (秒)
config COLLECTOR_SYNC_PERIODIC_SEC
    int "Periodic config sync interval"
    default 600
    range 60 3600
    help
        Interval for collector to actively query server config.
        Lower = more responsive, higher = less network traffic.

# HTTPS OTA (T07)
config COLLECTOR_OTA_USE_HTTPS
    bool "Use HTTPS for OTA"
    default y

config COLLECTOR_OTA_VERIFY_CERT
    bool "Verify server certificate"
    default y
    depends on COLLECTOR_OTA_USE_HTTPS

choice COLLECTOR_OTA_TRUST_ANCHOR
    default COLLECTOR_OTA_CRT_BUNDLE
    depends on COLLECTOR_OTA_VERIFY_CERT
config COLLECTOR_OTA_CRT_BUNDLE
    bool "Mozilla CA bundle (公网)"
config COLLECTOR_OTA_CUSTOM_CERT
    bool "Embed custom CA cert (内网)"
endchoice
```
