# 单用户认证初始化与运维指南

## 目标

系统只保留唯一活动认证主体 `system_admin`。设备、节点、通道和固件仍是全局资源，不新增租户归属字段。登录、JWT、密码、REST/WebSocket 鉴权和安全审计继续保留。

## 数据库与安装

系统仅支持全新数据库，不兼容旧数据库或旧用户数据。部署新版本前应准备全新的数据库，后端启动时通过 GORM `AutoMigrate` 创建当前 schema。

执行 `ehomectl auth bootstrap-database` 创建固定的 `AuthState=uninitialized` 行，再执行 `ehomectl auth create-initialization-token` 获取一次性初始化凭据。

初始化后活动账户必须满足：

- `subject_key = 'system_admin'`
- `retired_at IS NULL`
- `enabled = true`
- `session_version >= 1`
- `AuthState = initialized`

AuthState 缺失、账户数量异常或主体键异常时系统进入 `migration_required` 并拒绝登录，运行时不会自动重建 `uninitialized`。

## 管理员初始化

生产环境不再自动创建默认管理员，也不存在固定默认密码。初始化凭据为一次性 `selector.secret`：数据库仅保存 secret 哈希，完整凭据只由本机 CLI 显示一次。初始化在事务中创建唯一账户、消费令牌、写审计并更新 AuthState。

本地开发环境执行 `make clean` 后，下一次执行 `make up`（或 `make backend`）会自动引导空数据库：Makefile 调用 `ehomectl auth bootstrap-database` 创建 `uninitialized` 状态，并在终端输出 10 分钟有效的一次性初始化凭据。打开登录页后，将该凭据粘贴到“首次运行设置”表单，填写管理员用户名、至少 8 位密码和可选邮箱即可完成初始化。凭据不会写入前端代码或日志文件；若凭据过期，可在项目目录执行 `make auth-bootstrap` 重新生成。

Docker Compose 也支持通过环境变量直接完成首次管理员初始化。部署前在 `.env` 中同时设置 `EHOME_ADMIN_USERNAME` 和 `EHOME_ADMIN_PASSWORD`（密码至少 8 位，可选 `EHOME_ADMIN_EMAIL`），然后执行 `docker compose up -d`。服务只会在 `AuthState=uninitialized` 且数据库没有用户时执行一次初始化，后续重启不会覆盖管理员；如果只设置其中一个变量，服务会启动失败并明确提示配置不完整。初始化成功后应从 Compose 环境配置中移除管理员密码。

## API 变更

保留：

- `POST /api/v1/auth/login`
- `GET/PATCH /api/v1/account`
- `POST /api/v1/account/password`
- `POST /api/v1/account/logout-all`
- `POST /api/v1/auth/logout`（认证组内，全局撤销）

旧 `/api/v1/users` CRUD 先认证，兼容期统一返回 `410 MULTI_USER_API_REMOVED`。不把指定用户操作映射为唯一管理员操作。

密码修改和登出原子递增 `session_version`，旧 REST Token 立即 401，并生成 `session.revoked` outbox 事件用于 WebSocket 断连。

## 安全边界

- `/health` 是唯一无认证健康端点。
- Prometheus 移到认证路径 `/api/v1/metrics/prometheus`。
- 固件下载要求绑定文件名和过期时间的 HMAC ticket。
- REST CORS 只接受 `EHOME_ALLOWED_ORIGINS` 明确列表。
- 通用和终端 WebSocket 只接受同源或同一 allowlist。
- `EHOME_DEV_BYPASS_AUTH` 已退役，开发环境使用真实认证。

## 回滚

本版本不提供旧数据库兼容回滚。需要恢复时，应使用与当前版本匹配的全量数据库备份和应用版本；不得将当前 schema 与旧版本应用混用。

```bash
cd backend
go test ./...
EHOME_TEST_DB=postgres EHOME_DB_HOST=localhost EHOME_DB_PORT=5435 EHOME_DB_USER=ehome EHOME_DB_PASSWORD='[REDACTED]' EHOME_DB_NAME=ehome_test go test ./internal/auth ./internal/models

pnpm typecheck
pnpm exec vitest run --maxWorkers=2
pnpm build
```

测试/日志不得打印密码、完整 JWT、初始化凭据或数据库连接密码。
