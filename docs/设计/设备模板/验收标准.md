# 设备模板 — 验收标准

## 一、前端验收

### 1.1 模板列表
- [ ] 4 个统计卡 (总数/启用/总线类型/设备类型)
- [ ] 关键词搜索 + 设备类型/硬件/状态筛选
- [ ] 卡片显示: 名称/描述/设备类型/硬件/协议/parser/默认徽章
- [ ] 卡片操作: 预览/克隆/编辑/设为默认/启停/导出/删除

### 1.2 模板创建/编辑
- [ ] Cascader 选驱动 (OEM→种类→型号)
- [ ] 5 种硬件类型自适应表单
- [ ] 参数配置 JSON 编辑
- [ ] 设为默认开关

### 1.3 应用模板 (设备创建 Step 0)
- [ ] "使用配置模板" 下拉显示所有模板
- [ ] 选模板后自动套用 device_type/hardware_type/protocol
- [ ] 绿色提示条 "已套用模板"
- [ ] 选模板后自动选对应解析器
- [ ] "不使用模板" 时直接选解析器

## 二、后端验收 (P3 修复后)

- [ ] `GET /api/v1/device-configs` 返回 list+total
- [ ] `GET /api/v1/device-configs?device_type=bmp280` 过滤
- [ ] `GET /api/v1/device-configs/default/:device_type` 默认模板查询
- [ ] `POST /api/v1/device-configs` 创建 (11 字段持久化)
- [ ] `PUT /api/v1/device-configs/:id` 更新
- [ ] `DELETE /api/v1/device-configs/:id` 删除
- [ ] `POST /api/v1/device-configs/:id/default` 设为默认
- [ ] 必填字段 (name/device_type/hardware_type) 缺 → 400
- [ ] 默认模板互斥 (事务)
