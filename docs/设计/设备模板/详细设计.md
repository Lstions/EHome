# 设备模板 — 详细设计

## 1. 功能概述

设备模板 (DeviceConfig) 是设备级元数据模板, 用于创建设备时一键套用。

## 2. 数据模型

```sql
CREATE TABLE device_configs (
  ID             SERIAL PRIMARY KEY,
  Name           VARCHAR(128) NOT NULL,
  Description    TEXT,
  DeviceType     VARCHAR(64) NOT NULL,
  Protocol       VARCHAR(32),
  HardwareType   VARCHAR(32) NOT NULL,
  ParserID       VARCHAR(64),
  Config         TEXT,                    -- JSON
  IsDefault      BOOLEAN DEFAULT false,
  Status         VARCHAR(20) DEFAULT 'active',
  CreatedAt      TIMESTAMPTZ,
  UpdatedAt      TIMESTAMPTZ
);

CREATE INDEX idx_device_configs_devicetype ON device_configs(device_type);
CREATE INDEX idx_device_configs_default ON device_configs(is_default);
```

## 4. 应用模板 (创建设备 Step 0)

```
Step 0: 选模板
  ↓
onTemplateSelected(templateId)
  ↓
deviceForm.device_type = tpl.device_type
deviceForm.hardware_type = tpl.hardware_type
deviceForm.protocol = tpl.protocol
  ↓
自动选对应解析器 (parser_id 匹配)
  ↓
绿色提示条: "已套用模板: <name>"
```

## 5. 默认模板机制

- `is_default=true` 的模板按 device_type 唯一 (互斥)
- 创建/更新时若标默认 → 自动取消同 type 其他默认
- 查询默认: `WHERE device_type=? AND is_default=true AND status='active'`
- 兜底: 任意 active 模板 (按 id DESC 排)

详见 [设计/设备模板/详细设计 §5](../设备/详细设计.md) 复用

## 6. 容错设计

| 场景 | 行为 |
|------|------|
| 必填字段缺失 (name/device_type/hardware_type) | 400 |
| 删除被引用的模板 | 检查 devices 表外键 |
| 解析 config JSON 失败 | 存原始字符串, 读取时容错 |
| 默认模板已存在 | supersede (事务式取消旧默认) |
