## 三、节点端验收

> 通知中心是纯 Server 侧功能, ESP32 不感知通知。

- [ ] N/A — ESP32 不持有通知机制
- [ ] 但 ESP32 产生的异常 (解析错误/OTA 失败/离线) 由 Server 侧自动生成通知
- [ ] 通知来源字段 `source` 包含 `node:{id}` / `edge_device:{id}` / `ota:{task_id}`

## 四、集成验收

- [ ] 节点离线 → 10min 后前端顶栏铃铛 +1
- [ ] 边缘设备解析错误 → 铃铛 +1 + 详情页通知列表出现
- [ ] OTA 失败 → 铃铛 +1 + 错误消息可见
- [ ] "全部已读" → 角标清零
