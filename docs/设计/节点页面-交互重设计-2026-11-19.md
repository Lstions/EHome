## 0. 结论先行

1. **总线页从「表格 + 说明卡 + 工具卡」改为「资源主从工作台」**：左列资源、右列该资源的通道与操作。资源与通道的从属关系第一次在一屏内成立，主操作固定在右栏标题行。
2. **GPIO/PWM 从总线页移出**，只保留在「外设」；总线页只处理真正进通道体系的 I2C / UART / SPI / ADC。同一份资源不再出现在两个页签里。
3. **DMA 页从只读卡片改为「分配清单」**：可按状态筛选、看到绑定对象、直接解绑或跳转到对应资源，并解释「解绑后回退中断/轮询」「DMA 不足只是降级告警」。
4. **外设页按 GPIO / PWM 分域，动作就地完成**：输出引脚用开关、输入引脚用「读取」、PWM 用启停 + 占空比滑杆；只有「配置」进抽屉，不再为一次写电平来回开关弹窗。
5. **日志与终端各自成为完整工具**：日志把「实时 / 历史」拆成二级页签，终端改为「通道列表 + 终端 + 发送区」三段式；两者都不再和别的卡片抢垂直空间。

## 1. 现状复盘

### 1.1 现场可见的问题（以 2026-11-19 截图为准）

| # | 现象 | 后果 |
|---|---|---|
| 1 | 资源表「DMA 绑定」列文案溢出，压住右侧「查看 / 新建通道」 | 列不可读，操作被遮挡 |
| 2 | 右栏「资源详情」逐行重复左表内容，且大量空值 | 一屏两个真相源，用户不知道看哪边 |
| 3 | 「新建 I2C 通道」卡展示的是「创建表单支持的字段」，不是表单 | 用户以为能在卡里填，实际还要再点一次按钮 |
| 4 | 「查询资源」出现两次（顶部提示条 + 总线工具卡），「新建通道」出现三次 | 入口重复，主次不分 |
| 5 | 工具卡占满左栏，主任务（建通道、看通道）被挤到首屏之外 | 最高频动作要滚动才能看到 |
| 6 | 「已创建通道」整块在资源表与详情之下 | 资源→通道的层级断裂，用户要来回滚 |
| 7 | 选中资源只有 12px 单选点，右栏与左行没有视觉关联 | 不知道右栏在描述哪一行 |
| 8 | DMA 页签只读，没有解绑/跳转 | 看到问题却无法处置 |
| 9 | 外设页一张表混排 GPIO 与 PWM，配置全靠弹窗 | 现场读写要反复开关弹窗，状态与动作分离 |
| 10 | 日志实时区与历史区上下堆叠 | 两块互相挤占，都要滚动 |
| 11 | 终端缺少通道上下文，发送区与记录区割裂 | 不知道当前在哪个通道上收发 |
| 12 | 移动端宽表被压缩成竖排文字（如「发/送/·/接/收」），操作列被挤出屏幕 | 手机上不可用 |

### 1.2 真实操作路径与断点

| 路径 | 用户目标 | 现状步骤 | 断点 |
|---|---|---|---|
| P1 建通道 | 在某条资源上建采集实例 | 选总线类型 → 找资源 → 选中 → 找「新建通道」（行内/右卡/底部）→ 弹窗填表 | 入口三处、表单入口是静态说明、资源与通道不在同一视线 |
| P2 改通道 | 改参数/波特率/删除 | 基本信息通道健康 → 编辑；或总线页 → 滚到底部「已创建通道」→ 配置 | 通道列表不在资源上下文里；两条路径口径不同 |
| P3 配 DMA | 给资源绑/换/解绑 DMA | 资源表窄列选择器；或 DMA 页看一眼再回来 | 选择器列宽不足；DMA 页不能处置 |
| P4 现场接线 | 读/写 GPIO、启停 PWM、调占空比 | 外设页表格 → 开关/读取 → 配置弹窗 → 保存 | 动作与配置混在一起；弹窗打断现场节奏 |
| P5 排障 | 看设备、升级、日志、终端 | 关联设备 → 设备详情；OTA 历史；系统日志；通道终端 | 日志两块互相挤占；终端无上下文 |

### 1.3 根因

- **层级没有落到布局上**：资源、通道、设备是三层，但页面把它们平铺成「表 + 卡 + 表」。
- **说明性内容占了主内容的位置**：表单字段说明、工具卡、重复提示条，挤掉了高频动作。
- **只读与可写分离**：DMA 的查看与处置在两个页签，且处置入口过窄。
- **移动端按桌面缩放**：宽表被压缩，而不是重排或横滑 + 固定操作列。

## 2. 设计目标与原则

| 原则 | 落地方式 |
|---|---|
| 一屏一任务 | 总线页只回答「资源与它的通道」；DMA 页只回答「谁占了哪条」；外设页只回答「现在怎么读写」 |
| 选中即上下文 | 左列选中资源，右列全部内容都属于它；标题、通道、设备、DMA 都跟着走 |
| 主操作固定 | 每个页签工具栏右侧只放一个主按钮；局部动作放在所属区块标题行 |
| 层级可见 | 资源 → 通道 → 挂载设备在同一条视线上；总线页不再出现 GPIO/PWM |
| 就地完成 | 电平、启停、占空比、解绑等高频动作在行内完成；只有「配置」进抽屉 |
| 只读也要有出路 | DMA 清单可直接解绑/跳转；空态给下一步，而不是只写「暂无」 |
| 移动端重排 | 资源横滑、统计横滑、宽表横滑 + 操作列固定，而不是压缩列宽 |

## 3. 新信息架构

### 3.1 页签职责

| 页签 | 回答的问题 | 主操作 | 不再包含 |
|---|---|---|---|
| 总线与通道 | 这台节点有哪些总线资源？每条资源上有什么通道？ | 新建通道 | GPIO/PWM、静态表单说明、重复工具卡 |
| 外设 | 引脚现在什么状态？怎么读写？ | 配置引脚/PWM | 通道概念 |
| DMA 分配 | 哪条 DMA 被谁占用？ | 解绑 / 去绑定 | 只读卡片堆叠 |
| 关联设备 | 这台节点挂了哪些设备？数据新不新？ | 创建设备 | — |
| 固件升级 | 现在什么版本？升级到哪了？ | 发起升级 | — |

## 4. 逐页签设计

### 4.1 总线与通道

**结构**：工具栏（总线类型分段 + 搜索 + 查询资源 + 新建通道）→ 左资源列（卡片）→ 右资源详情（标题/动作 → 参数条 → 通道表 → 挂载设备 → 说明）。

| 元素 | 设计要点 |
|---|---|
| 总线分段 | 只保留 I2C/UART/SPI/ADC；每项带资源数徽标；切换后自动选中第一条并清空扫描结果 |
| 资源卡 | 名称 + 可用状态、引脚、模式与参数、通道数、DMA 摘要；选中态用左侧蓝条 + 浅蓝底，而不是小圆点 |
| 详情标题行 | 资源名 + 类型标签 + 状态；右侧固定「地址扫描（I2C）/ DMA 选择」；改波特率收进单条通道配置 |
| 参数条 | 引脚、工作模式、关键参数、当前波特率（UART）或已挂载通道数；只读事实用浅底条，不逐行重复成表格 |
| 通道表 | 通道名 + #ID、参数、边缘设备数、状态、配置/删除；状态与操作同列，删除走危险确认 |
| 挂载设备条 | 该资源通道上的设备以 chip 展示（名称 + 地址 + 在线点），一键跳关联设备；把「资源→通道→设备」串起来 |
| 新建通道 | 右侧抽屉（440px），按总线类型给字段；I2C 扫描结果以地址 chip 出现，点「填入」直接带入从机地址 |
| 空态 | 无资源：「该节点未上报此类型资源」+ 查询资源；有资源无通道：说明通道是什么 + 主按钮 |
| 离线 | 顶部提示条 + 所有写操作禁用；资源与通道仍可查看 |

**与原版的关键差异**：删除「新建通道字段说明卡」与「总线工具卡」；「查询资源」只保留工具栏一处；通道列表进入资源详情，不再沉到页面底部；GPIO/PWM 不再出现在总线类型里。

> **2026-11-19 裁决**：移除「批量改波特率」入口。波特率只在单条通道的「配置」抽屉里修改，避免一次误操作让整条总线上的设备同时失联。

### 4.2 外设

**结构**：GPIO / PWM 分段（带数量）+ 配置摘要（已配置/未配置/被占用）+ 状态筛选 + 刷新 → 当前类型的表。

| 区域 | 设计要点 |
|---|---|
| GPIO 表 | 引脚、标签、方向、运行状态、操作；输出引脚用开关写电平，输入引脚用「读取」，配置进抽屉 |
| 占用与未配置 | 被总线占用的引脚显示占用者，不提供配置；未配置行给「配置」按钮 |
| PWM 表 | 资源、频率、分辨率、运行状态、占空比、操作；运行中可在行内拖滑杆（300ms 防抖），启停按钮就地切换 |
| 配置抽屉 | GPIO：方向、初始电平（仅输出）、标签；PWM：频率、分辨率、自动启动、标签；引脚/资源只读 |
| 离线 | 顶部提示条 + 写入/读取/配置全部禁用，保留最后已知状态 |
| 空态 | 「等待节点硬件资源上报」；配置存在但设备未上报时标注「无效配置」 |

**与原版的关键差异**：GPIO 与 PWM 不再混在一张表；写电平/读取/启停/占空比全部行内完成，配置才开抽屉；离线态从「隐式禁用」变为显式说明。

### 4.3 DMA 分配

**结构**：摘要（总数/已分配/空闲/已禁用）+ 状态筛选 chip + 刷新 → 分配表 → 分配规则与固件关系两张说明卡。

| 列 | 内容 |
|---|---|
| 通道 | 名称 + CH 编号 |
| 能力 / 最大突发 | 发送·接收·突发；字节数 |
| 状态 | 已分配（绿）/ 空闲（蓝）/ 已禁用（灰） |
| 绑定资源 | 资源名可点，跳到「总线与通道」并选中该资源 |
| 可服务总线 | UART / I2C / SPI |
| 操作 | 已分配 → 解绑（危险确认）；空闲 → 去绑定；已禁用 → 无操作 |

**与原版的关键差异**：从「只读卡片墙」变为「可筛选、可跳转、可解绑」的分配清单；补上「一个资源只能绑一条」「解绑回退中断/轮询」「DMA 不足只是降级告警」三条解释，避免把告警误读为故障。

### 4.4 关联设备

- 工具栏：搜索（名称/地址）、通道筛选、状态筛选、列表/卡片切换、刷新、创建设备。
- 表格：设备（名称+类型）、通道/地址、最新读数（最多两个 chip）、状态、最后数据、查看。
- 等待中的设备不变暗（与状态徽标同口径）；离线/禁用/故障才变暗。
- 底部显示「共 N 台」；超过单次上限时显式提示，而不是静默截断。

### 4.5 固件升级

- 顶部摘要：当前版本、协议版本、上次升级、发起升级；**升级进行中时按钮禁用并显示「升级进行中」**。
- 状态筛选 chip：全部 / 进行中 / 成功 / 失败。
- 表格：版本（旧→新）、状态、进度、开始时间、耗时、操作；进度条按状态着色（成功绿、失败/超时红、需要重试橙、进行中蓝）。
- 只有等待中/下载中可取消；取消走危险确认；强制升级带「强制」标记与理由。

### 4.6 日志

- 二级页签：实时日志 / 历史日志，避免上下堆叠互相挤占。
- 实时：日志流开关、级别、暂停滚动、清屏、导出；深色终端铺满宽度；贴底跟随，上滚后出现「N 条新日志 · 回到底部」；本地保留上限 5000 行。
- 历史：时间范围、级别、Tag、关键词、查询；结果表格 + 分页 + 导出；清理全部/按时间清理走危险确认。
- 离线：提示「离线期间不会产生新日志」，但保留查看与导出。

### 4.7 终端

- 左侧通道列表（按总线分组、可搜索、显示参数），右侧终端。
- 终端头部：通道名 + 类型 + 参数 + 暂停/清空/导出。
- 记录区：时间、TX/RX、字节数据；错误帧带错误码；深色背景，TX/RX 用蓝/绿区分。
- 发送区：HEX/ASCII、输入框、发送；HEX 偶数长度校验；发送后先乐观提示，再等回包。
- 移动端：左侧列表改为顶部通道选择器，终端与发送区纵向排列。

## 5. 跨页签一致性

| 项 | 规则 |
|---|---|
| 工具栏 | 左侧是范围切换/筛选，右侧是主操作；主操作全页只有一个 |
| 抽屉 | 所有「新建/配置」统一从右侧 440px 抽屉进入，不整页跳转；底部固定取消/提交 |
| 危险确认 | 删除通道、解绑 DMA、取消升级、清理日志统一走危险确认，写明后果 |
| 空态 | 一句结论 + 一句下一步 + 一个主按钮；不使用「暂无数据」 |
| 状态色 | 绿=正常/成功，蓝=进行中/空闲，橙=警告/需要重试，红=失败/故障，灰=离线/禁用 |
| 占位 | 未知统一「—」；0 与未知不混用 |
| 密度 | 表格行高 44–48px；卡片圆角 10px；控件高度 32/34px；移动端触控目标 ≥44px |

### 5.1 字体标尺

全页只使用六级字号、三档字重，禁止出现 10.5 / 11.5 / 12.5 / 13.5 这类半像素字号。

| 层级 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| 页面标题 | 22 / 30 | 600 | 页头节点名；移动端降为 20 / 28 |
| 区块标题 | 16 / 24 | 600 | 资源详情标题、摘要数字 |
| 卡片标题 | 14 / 20 | 600 | 资源名、表格主名称 |
| 正文 | 13 / 20 | 400 | 表格、表单、按钮、页签 |
| 次要 | 12 / 18 | 400 | 引脚、参数、提示、表头 |
| 微文案 | 11 / 16 | 400 | 角标、chip、时间戳 |

- 字体族：正文使用系统中文栈；所有等宽场景（引脚、地址、HEX、日志）统一走同一个 `--mono` 变量。
- 数字：统计、延迟、进度、字节数使用 `font-variant-numeric: tabular-nums`，避免跳动。
- 字重只用 400（正文）/ 500（页签、选中态、主按钮）/ 600（标题）；不再使用 700。

### 5.2 Tab 与动效

- **页签不允许因选中而改变字重**：所有页签统一 `font-weight: 500`，选中只改颜色并显示 2px 下划线；下划线用 `scaleX` 从 0.55 展开到 1，不占布局。
- 页签宽度因此完全稳定（实测 8 个页签切换前后宽度零漂移）。
- 动效只服务于「状态变化可被察觉」，统一 120–240ms，使用同一条缓动曲线：

| 场景 | 动效 | 时长 |
|---|---|---|
| 页签切换 | 内容淡入 + 上移 6px | 220ms |
| 页签下划线 | 透明度 + 横向展开 | 180 / 220ms |
| 按钮 | hover 变色、按下下沉 1px | 120–160ms |
| 资源卡 | hover 上浮 1px + 阴影 | 160ms |
| 表格行 | hover 背景过渡 | 140ms |
| 抽屉 / 遮罩 | 右侧滑入 + 遮罩淡入 | 220 / 180ms |
| 进度条 | 宽度过渡 | 450ms |
| 日志 / 终端行 | 新行淡入 + 上移 3px | 160ms |

- `prefers-reduced-motion: reduce` 下关闭全部过渡与动画，不影响功能。

### 5.3 图标对照

| 位置 | 图标语义 | 说明 |

## 8. 验收清单

| 编号 | 场景 | 预期 |
|---|---|---|
| AC-R01 | 进入总线页 | 首屏同时看到资源列表、选中资源的通道、主操作「新建通道」 |
| AC-R02 | 切换总线类型 | 自动选中第一条资源，详情与通道随之切换，扫描结果清空 |
| AC-R03 | 在无通道的 I2C 资源上建通道 | 抽屉预填资源与类型字段；保存后通道出现在该资源下 |
| AC-R04 | I2C 地址扫描 | 结果以地址 chip 出现，点「填入」带入从机地址 |
| AC-R05 | 绑定/解绑 DMA | 详情内选择器完成；绑定后资源卡与 DMA 清单同步；解绑需确认 |
| AC-R06 | 外设页写电平 | 行内开关立即反馈「写入中」，成功后状态更新；失败可重试 |
| AC-R07 | PWM 调占空比 | 运行中才可拖；拖动只改本地，停止 300ms 后下发并提示 |
| AC-R08 | DMA 页筛选 | 全部/空闲/已分配/已禁用数量与表格一致 |
| AC-R09 | DMA 页解绑 | 二次确认后状态变空闲，绑定资源清空，总线页同步 |
| AC-R10 | 日志切实时/历史 | 两个视图独立，切换不丢筛选；实时贴底跟随 |
| AC-R11 | 终端发送奇数 HEX | 提示「无效的 HEX 数据（需偶数长度）」且不发送 |
| AC-R12 | 移动端总线页 | 资源卡横滑，详情纵向，宽表横滑且操作列固定 |
| AC-R13 | 离线节点 | 写操作禁用并说明；资源/通道/设备/日志仍可查看 |
| AC-R14 | 键盘操作 | 页签、资源卡、通道行、表格动作均可聚焦与激活 |
| AC-R15 | 切换任意页签 | 页签宽度与字重不变，只有颜色与下划线变化，不出现横向跳动 |
| AC-R16 | 全页字号抽查 | 只出现 11/12/13/14/16/22 六级字号；标题、正文、次要信息层级可辨 |
| AC-R17 | 动效与减弱动效 | 页签、抽屉、表格行、终端行有 120–240ms 过渡；系统开启「减少动态效果」后全部关闭 |
| AC-R18 | 批量改波特率 | 页面不存在该入口；波特率只在单条通道的「配置」抽屉内修改 |

## 9. 待确认与非目标

**待确认**：

- 页签命名是否改为「总线与通道 / 外设 / DMA 分配 / 固件升级 / 日志 / 终端」（深链映射不变）。
- 总线页是否彻底移除 GPIO/PWM（本稿主张移除，统一到外设）。
- 新建通道/OTA 是否统一用右侧抽屉（本稿主张统一）。
- 移动端宽表采用「横滑 + 操作列固定」还是「行卡片化」（本稿先用前者，成本更低）。

**非目标**：

- 不新增后端能力；不伪造通道状态、延迟、I2C 扫描结果。
- 不做批量运维编排、拓扑图、数据趋势图。
- 不改变节点列表页与基本信息页的结构（仅沿用同一套视觉与交互规则）。

### 与设计稿的差异

- 新建通道仍复用现有 `ChannelManager` 抽屉，未重写表单；资源、总线类型、DMA 预选沿用现有能力。
- I2C 地址扫描结果只做只读 chip 展示；`ChannelManager` 没有地址 preset，未伪造「点击填入」。
- 关联设备、固件升级、日志、终端沿用现有内容结构，只统一页签、字体层级、卡片表面与进入动效。

- 真机联调：本机 `ehome-local` 栈（18080/18443）接入 C6 `F0F5BD02F35C`（fw 2.9.0）后，页面显示真实能力与在线状态；实拍见 [real-node-bus.png](../../designs/node-page-redesign-2026-11-19/implementation/real-node-bus.png)。

- 2026-11-20 修复：GPIO/PWM 命令响应统一走 API envelope（`data.request_id`）；前端缺少 `request_id` 时直接报错，不再回退为 0。此前后端返回裸 JSON，前端拿到 `request_id=0`，WS `PeriphRsp` 无法关联，界面会永久停在「正在写入」。
- 批量改波特率已移除；单条通道的波特率仍在「配置」抽屉中修改。
