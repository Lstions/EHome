### 4.2 v2.1 同步场景 (新增, 11 个)

| ID | 场景 | 期望结果 | 状态 |
|----|------|---------|------|
| **SYNC-INT-001** | 首次上线 (NVS 空) | Hello → SyncGate 决策 Full (nvs_has=false) → ConfigManifest → 启动 | [ ] |
| **SYNC-INT-002** | 重启 (epoch 一致) | Hello → SyncGate 决策 None (dedup) → 不下发 | [ ] |
| **SYNC-INT-003** | 重启 (epoch 落后) | Hello → SyncGate 决策 Full (epoch_lag) → 下发 | [ ] |
| **SYNC-INT-004** | 恢复出厂 (NVS 空) | Hello → SyncGate 决策 Full (nvs_empty) → 强制下发 (修复 G3) | [ ] |
| **SYNC-INT-005** | 服务端 PUT /channels/123 | EmitConfigChange → SyncGate → 5s 内 ESP32 收到 (修复 G1) | [ ] |
| **SYNC-INT-006** | 服务端重启 | 5s 后 SyncGate.OnServerStartup → 10s 内 ESP32 收到 (修复 G2) | [ ] |
| **SYNC-INT-007** | 短暂断网 (offline→online) | StatusReport → SyncGate.OnStatusReport → 收到 (修复 G5) | [ ] |
| **SYNC-INT-008** | ESP32 周期 sync (10min) | ESP32 主动 ConfigQuery → 收到 ConfigSyncResponse 或 ConfigManifest | [ ] |
| **SYNC-INT-009** | 批量改 templates (5 个) | 1 个 ConfigChange 事件 → 5 个 SyncDecision → 5 个设备收到 | [ ] |
| **SYNC-INT-010** | HTTPS OTA 升级 | cert_pem 验证 + SHA256 校验 + 完成 | [ ] |
| **SYNC-INT-011** | WS 状态实时推送 | 拔网线 20s → 前端 Dashboard **实时**变 offline (无刷新, 修复 G4) | [ ] |
