# 采集器 — 验收标准

## 一、前端验收

### 1.1 采集器列表

- [ ] 列表显示 ID/device_id/名称/型号/固件版本/状态/最后心跳/RTT
- [ ] 状态徽章颜色: online=绿, offline=灰, unknown=黄
- [ ] 顶部 4 个统计卡 (总数/在线/离线/今日新增)
- [ ] 关键词搜索 (device_id/名称)
- [ ] 状态/平台/型号筛选
- [ ] 分页 (10/20/50 每页)
- [ ] 表格视图/卡片视图切换
- [ ] 实时 RTT 显示 (60s 刷新)

### 1.2 采集器详情

- [ ] 基本信息卡 (设备 ID/名称/型号/平台/固件/协议/状态/资源)
- [ ] 实时数据卡 (wifi_rssi/free_heap/uptime)
- [ ] 通道列表 (按硬件类型分组)
- [ ] 总线配置 (BusConfigPanel 嵌入)
- [ ] 设备列表 (该 collector 下)
- [ ] 触发 OTA 按钮
- [ ] 主动 Ping 按钮 → 立即显示 RTT

### 1.3 总线配置 (BusConfigPanel)

- [ ] 5 个 Tab: UART / I2C / SPI / GPIO / ADC
- [ ] 每种总线显示资源列表
- [ ] 资源点击 → 改波特率对话框
- [ ] 资源不可用 (collector offline) → 编辑按钮 disabled
- [ ] 改波特率后 → 重启资源 → 实时反馈

### 1.4 通道终端

- [ ] TX/RX 双面板日志
- [ ] HEX/ASCII 切换
- [ ] 按 channel 分组
- [ ] 发送 HEX 数据
- [ ] 虚拟滚动 (万条不卡)
- [ ] 清空按钮

## 二、后端验收

### 2.1 端点

- [ ] `GET /api/v1/collectors` 列表 (分页 + 过滤)
- [ ] `GET /api/v1/collectors/:id` 详情
- [ ] `POST /api/v1/collectors` 创建 (admin)
- [ ] `PUT /api/v1/collectors/:id` 编辑 (admin)
- [ ] `DELETE /api/v1/collectors/:id` 注销 (admin)
- [ ] `GET /api/v1/collectors/:device_id/channels` 该 collector 下 channels
- [ ] `GET /api/v1/collectors/:device_id/data` 该 collector 历史数据
- [ ] `POST /api/v1/collectors/:device_id/ping` 主动 ping

### 2.2 MQTT 处理

- [ ] `handler_hello.go` 处理 0x01 → 解析 + UPSERT + 发 HelloAck
- [ ] `handler_status.go` 处理 0x02 → 更新心跳字段
- [ ] `handler_data.go` 处理 0x03 → 解析 + 写 unified_data
- [ ] `handler_config.go` 处理 0x05 → 写 config_hash
- [ ] `ping_tracker.go` 计算 RTT
- [ ] MQTT 消息解析失败 → WARN + 跳过, 不影响其他消息

### 2.3 离线检测

- [ ] 30s 检测一次, 10min 阈值
- [ ] offline 时推 frontend 事件
- [ ] offline 时新增 notification
- [ ] last_seen 自动更新 (任何 MQTT 消息)
- [ ] 后端启动时从 DB 加载所有 collector, 触发一次检测

### 2.4 配置下发

- [ ] Hello 时计算 config_hash, 不一致则发 ConfigManifest
- [ ] ConfigResult (0x05) 收到后更新 hash
- [ ] hash 存储在 Redis (cache) + DB
- [ ] 手动改配置后下次 Hello 自动下发

## 三、采集器端验收

### 3.1 上线握手

- [ ] WiFi 连接成功 → 立即发 Hello (type=0x01)
- [ ] Hello 包含: device_id / firmware_version / model / channel_count / hardware_types
- [ ] 收到 HelloAck (0x12) → 解析 ConfigManifest → 写 NVS → 发 ConfigResult (0x05)
- [ ] HelloAck 解析失败 → WARN + 不写 NVS
- [ ] Hello 失败重试 3 次, 间隔 5s

### 3.2 心跳

- [ ] 60s/次发 StatusReport (type=0x02)
- [ ] 包含 uptime / free_heap / wifi_rssi / status_flags
- [ ] status_flags 包含: wifi_connected / mqtt_connected / config_synced

### 3.3 数据采集

- [ ] 按 device.interval_ms 定时触发数据采集
- [ ] 通过 bus 读物理层 (I2C/SPI/UART/GPIO/ADC)
- [ ] driver 解析 raw_data → 物理量
- [ ] 打包 DataReport (0x03) → pub mqtt.up

### 3.4 Ping/Pong

- [ ] 收到 Ping (0x08) → 立即发 Pong (0x09) 含原 timestamp
- [ ] MQTT 断时不缓存 Pong, 等待重连后重发

### 3.5 RGB LED 状态指示

- [ ] 开机: 白→蓝→青→绿慢闪
- [ ] WiFi 断开: 蓝色长亮
- [ ] MQTT 断开: 红色三闪
- [ ] OTA 进行中: 紫色呼吸
- [ ] 正常运行: 绿色慢闪
- [ ] 离线: 灰色慢闪

## 四、集成验收

### 4.1 端到端

- [ ] ESP32 上电 → 几秒内 Server 端看到 online
- [ ] 前端列表 → 该 collector 状态变绿
- [ ] 关闭 ESP32 → 10min 后 Server 端看到 offline
- [ ] 前端列表 → 该 collector 状态变灰
- [ ] 主动 Ping → RTT < 100ms
- [ ] 修改 Server 端 config → ESP32 下次 Hello 自动收到新配置
- [ ] OTA 触发 → 完整 6 状态机跑通
