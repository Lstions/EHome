# 系统监控 — 验收标准

> **版本**: v2.2
> **状态**: 已实现
> **关联**: [总体设计.md](../总体设计.md) | [00-术语表.md](../00-术语表.md)

## 一、前端 (admin only)
- [ ] 7 卡片指标 (节点/边缘设备/数据点/OTA/通知)
- [ ] 实时刷新 (30s)
- [ ] HTTP/MQTT/WS 资源图表
- [ ] 异常摘要卡片 (P2 已加)
- [ ] 时间范围趋势 (1h/24h/7d)

## 二、后端
- [ ] /api/v1/overview 返回所有聚合指标
- [ ] /api/v1/metrics/summary
- [ ] /api/v1/metrics/prometheus 标准格式
- [ ] 5+ 业务 counter/gauge/histogram

## 三、节点端验收

> 系统监控是纯 Server 侧功能, ESP32 不直接参与。

- [ ] N/A — ESP32 不提供系统级监控数据
- [ ] ESP32 的 StatusReport (0x02) 提供 free_heap/wifi_rssi/uptime 字段, 由 Server 聚合到监控面板
- [ ] OTA 进度由 ESP32 上报, Server 聚合到 OTA 统计卡片

## 四、集成验收

- [ ] admin 登录 → 跳 /monitor → 7 卡片指标正确
- [ ] operator 登录 → /monitor → 403
- [ ] 新边缘设备上线 → 30s 内在线数 +1
- [ ] Prometheus 抓取 /api/v1/metrics/prometheus → 标准格式
