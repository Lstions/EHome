## 1. 功能概述

站内通知统一呈现：配置同步失败、节点离线、OTA 结果、合并任务结果、告警（v3.4 起）。前端铃铛 + 未读计数 + 面板 + 全部已读；点击跳转目标页。

## 2. 数据模型

```sql
CREATE TABLE notifications (
  id, type, level, message, source, source_id,
  is_read, created_at, ...
);
```

- type 语义：info / warning / error / success（前端按 type 映射图标）。
- source 用于回链：如 source="alert_rule"、source_id=ruleID 跳转告警规则页。

## 3. 端点

| 端点 | 用途 |
|------|------|
| /notifications | 列表（分页 + 未读过滤） |
| /notifications/:id/read | 单条已读 |
| /notifications/read-all | 全部已读 |
| /notifications/unread-count | 未读数 |

## 4. 触发场景

| 事件 | 通知 |
|------|------|
| 配置下发失败 | warning，含节点与原因 |
| 节点离线 | warning |
| OTA 结果 | success/failed |
| 合并任务结果 | success/failed |
| 告警 firing/resolved（v3.4） | critical/warning（Source="alert_rule"） |

## 5. WebSocket 推送

- 事件：`notification`（id, level, message, timestamp）。
- 前端 MainLayout 铃铛监听推送实时刷新未读数。

## 6. 容错设计

- 通知写入失败不影响主业务路径（旁路写入）。
- 批量合并：同源同内容的连续事件合并计数（防刷屏）。
- 自动清理：过期通知定时清理，防止无限膨胀。
