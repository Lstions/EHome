# 数据采集 — 详细设计

> **版本**: v2.2
> **状态**: 设计中
> **关联**: [总体设计.md](../总体设计.md) | [00-术语表.md](../00-术语表.md)

## 1. 功能概述

数据采集 (Data Collection) 是 ESP32 端周期性读取物理传感器 → 解析 → 上报给 Server 的完整链路。

## 2. 数据模型 (Server 侧)

```sql
CREATE TABLE unified_data (
  ID              BIGSERIAL PRIMARY KEY,
  EdgeDeviceID    INTEGER REFERENCES edge_devices(id),
  ChannelID       INTEGER REFERENCES channels(id),
  Data            JSONB,                  -- 物理量 (e.g. {"temp": 23.5, "humidity": 65})
  ErrorCode       INTEGER DEFAULT 0,      -- HAL 错误码
  CollectedAt     TIMESTAMPTZ NOT NULL,   -- ESP32 采集时间
  ReceivedAt      TIMESTAMPTZ DEFAULT NOW(), -- Server 接收时间
  NodeID          INTEGER REFERENCES nodes(id),
  ParserID        VARCHAR(64)
);

CREATE INDEX idx_unified_data_edge_device ON unified_data(edge_device_id, collected_at DESC);
CREATE INDEX idx_unified_data_collected ON unified_data(collected_at DESC);
```

## 3. 关键流程

### 3.1 采集 → 上报

详见 [总体设计 §2.2](../总体设计.md#22-数据采集流-周期性)

```
[scheduler] 触发 (interval_ms)
  ↓
[bus] 读物理层
  ↓
[driver] 解析 raw_data
  ↓
[proto_engine] 打包 DataReport
  ↓
[mqtt_client] pub 到 nodes/{id}/up
```

### 3.2 接收 → 存储

```
[mqtt_handler] 收 DataReport
  ↓
[parser] 解析帧 → 提取 edge_device_id, channel_id, raw_data
  ↓
[driver] (server 侧) 解析 raw_data → 物理量
  ↓
[DB] INSERT INTO unified_data
  ↓
[ws] 推 data_update 事件
```

## 4. 状态机

无显式状态机, 但有生命周期:
```
创建 → 活跃 (写入) → 保留 (N 天) → 归档 (P3 计划)
```

## 5. 数据保留策略

- 默认: 7 天 (可配)
- 超过 7 天 → 自动清理 (cron job, P3)
- 高频采集: 5min 聚合 (P3 计划, 减少存储)

## 6. 容错

| 场景 | 行为 |
|------|------|
| 解析失败 | error_code 标记 + raw_data 进 notifications |
| 重复上报 (相同 collected_at) | UNIQUE 约束拒绝 + WARN |
| Server 接收延迟 > 5min | WARNING, 标记 stale |
| DB 不可达 | 进 Redis 暂存 + 重试 |
| 采集失败重试 | 3 次, 失败后 error_code=ETIMEDOUT |

## 7. 可观测性

| 事件 | 字段 |
|------|------|
| `data.received` | edge_device_id, channel_id, error_code |
| `data.parse_error` | edge_device_id, raw_data_hex, error_code |
| `data.stale` | edge_device_id, age_seconds |

| 指标 | 类型 | 标签 |
|------|------|------|
| `ehome_data_received_total` | counter | edge_device_id, status |
| `ehome_data_parse_error_total` | counter | error_code |
| `ehome_data_latency_seconds` | histogram | edge_device_id |
