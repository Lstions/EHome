# 多总线事件驱动架构

> **状态**: 已实现（v2.7 交付并合入 main：动态租约 + 事件驱动 RX + 控制/采样队列分离 + 异步报告；P0-P5 全落地）
> **版本**: v2.7
> **日期**: 2026-08-22
> **关联**: [总体设计.md](总体设计.md) | [ESP32固件架构.md](ESP32固件架构.md) | [../协议/二进制帧协议.md](../协议/二进制帧协议.md)

## 1. 背景与目标

单总线时代 ESP32 固件是"每通道一命令循环 + 固定 delay"模型。多总线（UART×2 + SPI + I2C）并行后暴露：阻塞式轮询拖垮吞吐、控制与采样互相踩踏、单点 cmd_task 瓶颈。v2.7 采用事件驱动改造：

- **动态接口分配**（Dynamic Lease）：总线接口不再静态绑定通道，按需租借。
- **事件驱动 RX**：UART 空闲检测 + 事件出发快通道，替代轮询读。
- **控制/采样队列分离** + 公平调度：控制命令不再被采样任务饿死。
- **异步 report task**：三档报告池独立于执行路径。

## 2. 架构组件

```
┌─────────────────── 采样路径 ───────────────────┐
scheduler（按 interval_ms 触发）
  → sample queue（per bus）
  → bus_worker（租约获取 → 执行 → 释放）
  → 事件驱动 RX（空闲检测分帧）
  → DataReport（0x03）

┌─────────────────── 控制路径 ───────────────────┐
ChannelCmdV2 (0x15) 到达
  → control queue（独立于采样队列）
  → bus_worker 公平调度（控制优先/轮转）
  → ACK(0x16) → 事务执行 → Final(0x17)

┌─────────────────── 报告路径 ───────────────────┐
report_task（异步，三档池：周期/事件/突发）
  → StatusReport / ResourceReport / ChannelCmdV2Final
  → 背压：有界队列 + 丢弃计数（report_drop_count）
```

## 3. 核心机制

### 3.1 动态租约（bus_lease_policy）

- 接口租约快照：每任务执行前从资源表按 manifest 动态申请，不再硬编码通道→接口映射。
- 租约持有期间互斥：同总线并发执行通过 lease 串行化；SPI 多 CS / I2C 多地址多从机按 hardware_id 路由。
- manifest 预检：配置应用前校验租约合法（防非法绑定）。

### 3.2 事件驱动 RX + 透明管道

- UART RX 空闲检测分帧（替代固定超时等长读），支持多帧乱序重组。
- 被动数据快速通道：DTE/总线事件直达报告路径，不经命令循环（降低延迟）。
- UART 透明管道模式：逐指令 ConfigManifest 下的原始字节事务（ChannelCmdV2 的信封）。

### 3.3 背压与隔离

- 每条队列独立容量（5 队列：UART0/UART1/UART2/SPI/I2C 的 current/high_water/skipped/rejected 指标入 StatusReport runtime_perf）。
- 报告队列丢弃计数上报告警；采样队列对控制队列无饿死（公平轮转调度）。

## 4. 协议增量（v2.7）

- **frame tag varint 化**：field ≥16 用多字节 varint tag（ChannelCmdV2 家族 0x15-0x17 等）。
- **ChannelCmdV2 (0x15)** + Ack(0x16) + Final(0x17)：见 [边缘设备控制.md](边缘设备控制.md) §3。
- **StatusReport 重写**（10 字段）：runtime_perf(field9) + control_stats(field10)。
- **ResourceReport**：新增 manifest_capacity(field10)。
- **WriteCmd**：新增 edge_device_id(field5) + rx_timeout_ms(field6)；legacy 保留（受控 read + 初始化兼容）。

详见 [../协议/二进制帧协议.md](../协议/二进制帧协议.md)。

## 5. 与 v2.5 之前的关键差异

| 维度 | 旧模型 | v2.7 |
|------|--------|------|
| RX | 固定读等待（delay_ms） | 事件驱动 + 空闲检测分帧 |
| 控制/采样 | 同一命令循环 | 队列分离 + 公平调度 |
| 接口分配 | 静态绑定 | 动态租约 + manifest 预检 |
| 报告 | 执行路径内联发送 | 独立 report_task 三档池 |
| 帧 tag | 单字节 | varint（f≥16 多字节） |
