# 通道 — 验收标准

> **版本**: v2.2
> **状态**: 设计中
> **关联**: [总体设计.md](../总体设计.md) | [00-术语表.md](../00-术语表.md)

## 一、前端验收

### 1.1 通道管理 (ChannelManager)
- [ ] 5 种硬件类型自适应表单
- [ ] UART: 波特率/数据位/停止位/校验/流控
- [ ] I2C: 从机地址 + 扫描按钮 + 时钟频率
- [ ] SPI: CS 引脚 + 模式 + 时钟
- [ ] GPIO: 方向/上拉/中断
- [ ] ADC: 通道/采样时间/衰减
- [ ] 通道参数说明 (按 driver capability 动态显示)

### 1.2 通道终端 (ChannelTerminal)
- [ ] TX/RX 双面板日志
- [ ] HEX/ASCII 切换
- [ ] 按 channel 分组
- [ ] 发送 HEX 数据
- [ ] 虚拟滚动
- [ ] 时间戳 + 错误码标签
- [ ] 清空按钮

### 1.3 总线配置 (BusConfigPanel)
- [ ] 5 个 Tab (UART/I2C/SPI/GPIO/ADC)
- [ ] 改波特率对话框
- [ ] 资源不可用时禁用编辑

## 二、后端验收

### 2.1 端点
- [ ] `GET /api/v1/channels` 列表
- [ ] `GET /api/v1/channels/:id` 详情
- [ ] `POST /api/v1/channels` 创建
- [ ] `PUT /api/v1/channels/:id` 更新
- [ ] `DELETE /api/v1/channels/:id` 删除
- [ ] `POST /api/v1/channels/i2c/scan` I2C 扫描

### 2.2 模型
- [ ] channels 表 + 索引
- [ ] JSONB config 序列化
- [ ] 软删除 (P3)

### 2.3 配置下发
- [ ] 改 channel config → 触发 ConfigManifest
- [ ] ConfigResult 收到后写 config_hash
- [ ] 失败回滚

## 三、节点端验收

### 3.1 5 总线
- [ ] UART 初始化正确 (baudrate/data_bits/parity)
- [ ] I2C 扫描 0x01-0x7F
- [ ] SPI CS 引脚正确拉低
- [ ] GPIO 中断触发
- [ ] ADC 读数稳定

### 3.2 ScanRequest
- [ ] 收到 ScanRequest → 扫描 → 发 ScanReport
- [ ] ScanReport 含边缘设备地址 + 协议类型

### 3.3 NVS 持久化
- [ ] 配置变更写 NVS
- [ ] 重启后从 NVS 加载
- [ ] NVS 损坏回退默认配置
