# 通道 — 详细设计

## 1. 功能概述

通道 (Channel) 是物理总线的逻辑抽象。每个 channel 属于一个 collector，对应一种硬件类型 (UART/I2C/SPI/GPIO/ADC)。

## 2. 数据模型

```sql
CREATE TABLE channels (
  id              SERIAL PRIMARY KEY,
  collector_id    INTEGER REFERENCES collectors(id),
  hardware_type   VARCHAR(16) NOT NULL,    -- uart/i2c/spi/gpio/adc
  hardware_id     VARCHAR(16) NOT NULL,    -- 物理 ID (0,1,2 / GPIO25)
  config          JSONB,                    -- 硬件配置
  enabled         BOOLEAN DEFAULT true,
  interval_ms     INTEGER DEFAULT 1000,
  parser_id       VARCHAR(64),              -- 关联的驱动
  created_at      TIMESTAMPTZ DEFAULT NOW(),
  updated_at      TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX idx_channels_collector ON channels(collector_id);
CREATE INDEX idx_channels_hw ON channels(hardware_type, hardware_id);
```

## 3. 5 种硬件类型

### 3.1 UART
| 字段 | 默认值 |
|------|--------|
| baudrate | 115200 |
| data_bits | 8 |
| stop_bits | 1 |
| parity | none |
| flow_control | none |
| rx_buffer_size | 1024 |
| tx_buffer_size | 1024 |

### 3.2 I2C
| 字段 | 默认值 |
|------|--------|
| clock_hz | 400000 |
| sda_pin | 21 |
| scl_pin | 22 |
| pullup_enabled | true |

### 3.3 SPI
| 字段 | 默认值 |
|------|--------|
| clock_hz | 1000000 |
| mosi_pin | 23 |
| miso_pin | 19 |
| sclk_pin | 18 |
| cs_pin | 5 |
| mode | 0 |

### 3.4 GPIO
| 字段 | 默认值 |
|------|--------|
| pin | 25 |
| direction | input/output |
| pull | none/up/down |
| interrupt | none/rising/falling/both |

### 3.5 ADC
| 字段 | 默认值 |
|------|--------|
| channel | 0 |
| attenuation | 0dB/2.5dB/6dB/11dB |
| sample_time | 100ms |
| voltage_range | 0-3.3V |

## 4. 关键流程

### 4.1 创建通道

```
前端 → POST /api/v1/channels
  ↓
[server] 校验 hardware_type 必填
  ↓
[DB] INSERT INTO channels
  ↓
[server] 发 ConfigManifest 给 collector (含新 channel 配置)
  ↓
[ESP32] 写 NVS → 发 ConfigResult
```

### 4.2 I2C 扫描

```
前端 → POST /api/v1/channels/i2c/scan {collector_id, hardware_id}
  ↓
[server] 发 ScanRequest (0x0D) 到 mqtt.down
  ↓
[ESP32] 扫描 0x01-0x7F → 发 ScanReport (0x0C) 含设备地址列表
  ↓
[server] 收到 ScanReport → 推 frontend 事件
  ↓
前端 → 显示发现的设备列表
```

## 5. 容错设计

| 场景 | 行为 |
|------|------|
| Channel 重复 (collector + hardware_type + hardware_id) | 409 Conflict + 提示 |
| 改配置失败 (ESP32 拒收) | 配置 rollback + notification |
| 资源冲突 (两设备用同一 channel) | 创建时检测, 阻止 |
| 扫描超时 | 30s 未回 ScanReport → 失败 |

## 6. 可观测性

| 事件 | 字段 |
|------|------|
| `channel.created` | channel_id, collector_id, hardware_type |
| `channel.config.changed` | channel_id, old_config, new_config |
| `channel.i2c.scan.complete` | collector_id, addresses_found |
| `channel.config.rollback` | channel_id, reason |

| 指标 | 类型 | 标签 |
|------|------|------|
| `ehome_channel_total_count` | gauge | hardware_type |
| `ehome_i2c_scan_duration_seconds` | histogram | collector_id |
