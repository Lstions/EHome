## 0. 阅读说明

### 0.1 本文解决什么问题

把「节点页面」当成一个产品对象，定义它**必须呈现什么事实、按什么规则判定、允许用户做什么**。
本文是页面级 PRD，可作为需求评审、测试用例设计、UI 走查与新人理解的统一依据。

### 0.2 边界（本文不写什么）

| 不写 | 原因 |
|---|---|
| 代码、组件名、文件路径、函数名 | 需求应独立于实现，换实现不应改需求 |
| 接口地址、请求方法、字段名、数据库列 | 属接口/数据字典范畴，见对应模块文档 |
| 协议帧格式、MQTT 主题、固件实现 | 见 [../协议/二进制帧协议.md](../协议/二进制帧协议.md) 与固件文档 |
| 具体像素、色值、栅格数值 | 属视觉稿与前端规范；本文只约束断点行为与信息层级 |

本文描述的是**业务事实与交互约束**；同一事实在不同页面的展示口径必须一致，冲突时以本文 §11 的校正表为准。

### 0.3 编号与用语

| 记号 | 含义 |
|---|---|
| 需求编号 | `ND-L-xx` 列表页、`ND-DH-xx` 页头、`ND-DS-xx` 统计条、`ND-DT-xx` 页签、`ND-DB-xx` 基本信息、`ND-DU-xx` 总线配置、`ND-DP-xx` 外设控制、`ND-DM-xx` DMA、`ND-DE-xx` 关联设备、`ND-DO-xx` OTA 历史、`ND-DG-xx` 系统日志、`ND-DC-xx` 通道终端、`ND-DX-xx` 对话框 |

| 在线 / 离线 | 见 BR-02 的判定口径；页面自身不计算在线状态 |

## 1. 页面定位

### 1.1 在系统中的位置

```text
平台（本系统）
  └─ 中心端：节点/通道/边缘设备/配置/数据的权威源
       └─ 节点（ESP32 整机）：总线 IO / 协议 / 采集执行 / 资源上报 / OTA
            └─ 边缘设备：挂在节点通道上的具体设备
```

节点页面是**中心端对节点的唯一可视化管理界面**：上承「这个节点是否健康」，下接「它挂了哪些总线资源、通道、设备和数据」。
节点本身无业务逻辑，页面上的一切状态都来自节点上报与中心端判定，页面不做二次推断。

### 1.2 两类页面的职责

| 页面 | 回答的问题 | 主要动作 |
|---|---|---|
| 节点列表 | 「有哪些节点、哪些在线、哪些需要处理」 | 检索、筛选、巡检、添加、删除、就地升级 |
| 节点详情 | 「这台节点现在怎么样，哪里不对，怎么处置」 | 判读状态、同步配置、升级、测延迟、重启/恢复出厂、配置总线与外设、管理通道与设备、看日志与终端 |

### 1.3 角色与典型场景

| 角色 | 场景 | 成功判据 |
|---|---|---|
| 运维 | 每日巡检：扫一眼列表，找出离线或告警节点 | 5 秒内判断「哪些节点不在线」；无需进详情 |
| 运维 | 单节点故障定位：某一节点数据不来 | 在详情页判断是「节点离线／配置未同步／通道异常／设备无数据」中的哪一类 |
| 实施 | 新节点接入后确认 | 详情页看到型号/固件/协议版本；通道与外设与现场一致 |
| 实施 | 现场总线调试 | 在总线配置与外设控制中读资源、改参数、扫描地址；在通道终端收发原始帧 |
| 研发支持 | 远程排障 | 读到最近事件、系统日志、实时日志与历史日志，能定位到设备侧行为 |
| 管理员 | 固件升级 | 在列表或详情发起升级，并在 OTA 历史看到进度与结果 |

### 1.4 页面设计原则

| 编号 | 原则 | 具体含义 |
|---|---|---|
| P1 | 真实数据优先 | 页面不编造、不估算、不用默认值冒充事实；未知统一显示「—」；0 与未知严格区分 |
| P2 | 能力驱动 | 设备没上报的能力不出现可操作入口；操作入口出现即代表「点了有意义」 |
| P3 | 离线可读、不可写 | 读操作不受在线状态限制；写操作在离线时禁用并说明原因，而不是让用户点了才失败 |
| P4 | 状态可解释 | 每个状态都有中文、颜色与口径；「未知」不得被显示成「正常」或「失败」 |
| P5 | 危险动作显式化 | 不可逆动作必须二次确认并写明后果；「结果未知」不得表述为「失败」 |
| P6 | 上下文不串台 | 切节点、切页签、重新登录后，旧请求/旧推送的结果不得落到新上下文 |

## 2. 信息架构与导航

### 2.1 导航与页面清单

| 路径 | 页面 | 入口 | 说明 |
|---|---|---|---|
| `/node` | 节点列表 | 侧栏「节点」 | 默认卡片视图；分页展示 |
| `/node/:id` | 节点详情 | 列表卡片/行/「详情」 | 同一组件承载 8 个页签；`:id` 为设备 ID |
| `/node/:id/overview` | 节点总览 | 仅深链 | 与详情同一页面，用于兼容既有链接 |

页面自身不提供二级导航；顶部导航、侧栏与面包屑由框架提供。

### 2.2 深链参数

| 参数 | 作用域 | 取值 | 行为 |
|---|---|---|---|
| `?search=` | 列表 | 任意关键词 | 首屏即按该关键词检索（服务端全库） |
| `?status=` | 列表 | `online` / `offline` | 首屏即带状态筛选；其他取值忽略 |
| `?action=add` | 列表 | `add` | 进入页面即打开「添加节点」对话框（即使仍在加载骨架） |
| `?tab=` | 详情 | 见 §4.4 映射表 | 直达指定页签；未知取值忽略且不报错 |

设计意图：所有「页内状态」都可被链接表达，便于工单、告警通知、外部系统直接跳到目标视图。

### 2.3 面包屑与返回

- 面包屑**只由顶部框架提供**，页面内不再自建，避免同一屏出现两套路径。
- `/node`：`节点管理`（当前页，不可点）。
- `/node/:id`：`节点管理`（可点回列表）／`节点详情`（当前页）。
- `/node/:id/overview`：`节点管理`／`节点详情`／`节点总览`。
- 每一级都可点回上一级；页面内不再单独提供「返回」按钮。

### 2.4 页面结构总览

```text
节点列表 /node
├─ 统计概览（4 张）
├─ 工具栏（搜索／状态／型号／视图切换／添加／刷新）
├─ 当前筛选回显
├─ 卡片视图 或 表格视图
├─ 分页器
├─ 空状态
└─ 对话框：添加节点、OTA 升级

节点详情 /node/:id
├─ 页头（标题／重命名／状态／连接质量／设备 ID／动作区）
├─ 五格统计条（型号／固件／最后上线／在线时长／协议版本）
├─ 页签栏（8 个）
│   ├─ 基本信息
│   ├─ 总线配置
│   ├─ 外设控制
│   ├─ DMA 通道
│   ├─ 关联设备
│   ├─ OTA 历史
│   ├─ 系统日志
│   └─ 通道终端
└─ 页内对话框：重命名、全部事件、OTA、通道配置、快速创建设备
```

### 2.5 页面间跳转

| 起点 | 终点 | 携带信息 | 目的 |
|---|---|---|---|
| 列表卡片「配置」 | 详情·总线配置页签 | 节点 ID + 页签 | 直达配置现场 |
| 列表「升级」 | 本页 OTA 对话框 | 节点 ID、型号、当前固件 | 不打断巡检节奏 |
| 详情·通道健康「查看全部」/通道行 | 通道管理 | 节点过滤 | 看该节点全部通道并编辑 |
| 详情·关联设备行/卡片 | 边缘设备详情 | 设备 ID | 看设备数据与操作 |
| 详情·资源详情「已挂载通道-查看」 | 通道管理 | 节点过滤 | 从资源跳到其上的通道 |

## 3. 节点列表页

### 3.1 页面目标与结构

目标：**在最短时间内回答「我的节点都在不在、需不需要我处理」**，并提供进入单体的入口。
列表默认卡片视图，便于扫读状态；表格视图适合对比型号、固件与延迟。两种视图展示同一份数据。

### 3.2 统计概览

| 编号 | 统计卡 | 口径 | 交互 |
|---|---|---|---|
| ND-L-01 | 本页节点 | 当前页返回的节点条数 | 点击＝清空状态筛选（回到「全部」） |
| ND-L-02 | 本页在线 | 当前页中状态为在线的条数 | 点击＝筛选在线 |
| ND-L-03 | 本页离线 | 当前页中状态为离线的条数 | 点击＝筛选离线 |
| ND-L-04 | 本页告警 | 当前页中状态为告警的条数 | 不可点击（仅展示） |
| ND-L-05 | 口径约束 | 四张卡都只统计**当前页**，不是全库；卡片标题必须写明「本页」，不得让用户误读为全局 | 与筛选结果同步更新 |

补充：节点状态当前只有「在线／离线」两种（见 BR-02），「告警」是为将来状态扩展保留的计数位，
在现网常态为 0；页面**不得**因此隐藏该卡，但也不得把它解释为「没有告警数据」。

### 3.3 检索与筛选

| 编号 | 能力 | 规则 |
|---|---|---|
| ND-L-06 | 关键词检索 | 服务端**全库**检索，匹配**名称或型号**，大小写不敏感；不含设备 ID；输入后 300ms 防抖再请求；清空立即生效（不等防抖） |
| ND-L-07 | 状态筛选 | 全部／在线／离线；离散选择，变更即请求 |
| ND-L-08 | 型号筛选 | 选项取自**当前页**出现过的型号（去重），不是全库型号清单；选中后由服务端做**精确**匹配并跨页检索 |
| ND-L-09 | 筛选一致性 | 任一筛选或关键词变化：页码归 1 → 重新请求；**不得**只重置页码不重查，也不得在本地二次过滤服务端结果 |
| ND-L-10 | 清空筛选 | 「清除全部」一次清空三个条件，只发一次请求；单个标签的关闭等价于清空该条件 |
| ND-L-11 | 筛选回显 | 存在任一筛选时显示「当前筛选：」＋可关闭标签（关键词／状态／型号）＋「清除全部」 |
| ND-L-12 | 深链初始化 | `?search=` 与 `?status=` 在首屏生效且只触发一次请求（不得因初始化再补发） |

型号筛选的已知限制：因为选项来自当前页，用户在 A 页看到的型号清单可能与 B 页不同。
这是**可接受的产品取舍**（服务端未提供全库型号枚举）；用户需要全库按型号找节点时，应使用关键词检索。

### 3.4 视图与信息项

| 编号 | 视图 | 信息项 | 约束 |
|---|---|---|---|
| ND-L-13 | 卡片视图（默认） | 名称、型号、状态胶囊、设备 ID、固件版本、连接质量、上线时间 | 在线时连接质量显示进度条＋百分比；离线显示「—」；离线卡片整体淡化 |
| ND-L-14 | 表格视图 | 节点（名称＋型号）、设备 ID、固件、状态、连接质量、延迟、上线时间、操作（详情／删除） | 表格行整体可点进详情；移动端必须提供横滑容器与「左右滑动」提示 |
| ND-L-15 | 名称回退 | 名称 → 「节点 设备ID」→「节点 主键」→「未命名节点」 | 任何位置展示节点名都必须走同一回退，不得出现空白标题或空引号 |
| ND-L-16 | 状态表达 | 在线／离线；在线圆点带呼吸动画 | 颜色不是唯一信息：必须同时有文字 |
| ND-L-17 | 可访问性 | 卡片与行可点击时必须键盘可达（Enter/Space）、有可读的无障碍名称、焦点可见 | 不得只靠鼠标事件 |

### 3.5 卡片／行内动作

| 编号 | 动作 | 规则 | 补充 |
|---|---|---|---|
| ND-L-18 | 打开详情 | 点整卡／整行／「详情」均进入 `/node/:id` | 动作按钮必须阻止冒泡，避免误跳转 |
| ND-L-19 | 配置 | 进入详情并直达「总线配置」页签 | 不得只改 URL 不生效 |
| ND-L-20 | 升级 | 在本页打开 OTA 升级对话框，携带节点 ID、型号、当前固件版本 | 不跳转固件管理页；列表页入口不按在线状态禁用，是否可升由升级闸门判定 |
| ND-L-21 | 删除 | 危险确认后删除；成功后本地移除、总数减一、统计更新，并后台重拉 | 重拉失败要明确提示「节点已删除，但列表刷新失败」 |

### 3.6 添加节点（手动注册）

| 编号 | 字段／规则 | 说明 | 补充 |
|---|---|---|---|
| ND-L-22 | 入口 | 工具栏「添加节点」、空状态快捷动作、深链 `?action=add` | 三处必须打开**同一个**对话框 |
| ND-L-23 | 设备 ID | 必填；12 位十六进制（0-9、A-F）；提交前去空格并转大写 | 格式不合法时**不发请求**，直接提示格式要求与示例 |
| ND-L-24 | 名称 | 可选；留空时列表与详情回退显示为「节点 设备ID」 | 不得用空字符串当标题 |
| ND-L-25 | 重复注册 | 已存在的设备 ID 必须提示「该设备 ID 已存在」 | 不得把服务端英文原文直接抛给用户 |
| ND-L-26 | 成功路径 | 提示成功 → 关闭对话框 → 清空表单 → 刷新列表 | 刷新后新节点应出现在列表中 |
| ND-L-27 | 表单状态 | 提交中按钮进入加载中状态并禁止重复提交；取消／关闭不提交 | 关闭后再次打开应为空表单 |

### 3.7 删除节点

- 二次确认文案必须包含节点名与「不可恢复」；确认按钮为危险样式，默认焦点落在取消侧。
- 删除成功后立即从当前页移除，并重新拉取列表；删除失败如实报错，不得假装成功。
- **已知语义**：服务端为软删除且**不级联**（通道、边缘设备、历史记录仍保留，见 G7）；页面文案不得承诺「连同设备一起删除」。

### 3.8 实时性与刷新

| 编号 | 能力 | 规则 | 补充 |
|---|---|---|---|
| ND-L-28 | 首屏 | 有缓存时直接渲染（不闪骨架）；无缓存时显示骨架（4 张统计卡＋8 张卡片） | 缓存有效期短（秒级） |
| ND-L-29 | 手动刷新 | 强制重取；按钮进入加载中状态；成功提示「数据已刷新」；失败提示并保留旧数据 | 不得清空列表再加载 |
| ND-L-30 | 状态推送 | 收到节点状态事件：当前页内对应节点**就地更新**（离线时连接质量归零），不整页重拉 | 避免屏幕闪烁 |
| ND-L-31 | 新节点推送 | 当前页找不到该节点时，500ms 防抖后**静默**重拉（不显示骨架） | 不得因一条推送刷屏 |
| ND-L-32 | 请求竞态 | 并发请求只允许最新一次落地；旧响应必须被丢弃 | 防止旧数据覆盖新数据 |

### 3.9 分页

| 编号 | 规则 | 说明 |
|---|---|---|
| ND-L-33 | 默认每页 20 条，可选 10／20／50 | 服务端分页，客户端不再切片 |
| ND-L-34 | 总数来自服务端「过滤后的全量」 | 分页器页数必须按全量计算 |
| ND-L-35 | 每页条数变化 → 回到第 1 页并重查 | 原页码在新页长下可能越界 |
| ND-L-36 | 翻页 → 携带当前全部筛选条件请求 | 筛选条件不得丢失 |

### 3.10 空态、加载、错误

| 编号 | 状态 | 表现 |
|---|---|---|
| ND-L-37 | 加载中 | 统计卡骨架＋卡片骨架；不得先渲染「暂无节点」再跳成列表 |
| ND-L-38 | 空列表 | 「暂无节点」＋说明「开始添加第一个节点来监控您的设备」＋「添加节点」快捷动作 |
| ND-L-39 | 请求失败 | 明确错误提示；保留旧数据；不得把失败显示成空列表 |
| ND-L-40 | 筛选后空 | 与「从未添加」区分：用户应能看出是筛选导致为空，并可一键清空筛选 |

### 3.11 列表页验收要点

- 四张统计卡的数字与当前页数据一致；点击前三张能正确切换状态筛选，第四张不可点。
- 关键词、状态、型号任一变化都会「页码回 1 并重新请求」，且请求参数正确。
- 清空筛选只发一次请求；筛选标签与列表状态同步。
- 卡片与表格的信息项、状态、连接质量、上线时间口径一致。
- 「添加节点」在格式非法时不发请求；重复设备 ID 显示中文提示。
- 删除需二次确认；成功后列表即时更新；失败有明确提示。
- 状态推送能就地更新；未知节点会触发一次静默刷新。

## 4. 节点详情页

### 4.1 页面结构

详情页是**单体运维工作台**：页头给结论，统计条给事实，页签给证据与处置手段。
信息层级必须保证「不进任何页签就能判断节点是否正常」。

### 4.2 页头

| 编号 | 元素 | 规则 |
|---|---|---|
| ND-DH-01 | 标题 | 名称优先；无名称显示「节点 设备ID 前 8 位」；不得出现空标题 |

### 4.6 总线配置页签

本页签回答两个问题：**这台节点有哪些硬件资源**、**这些资源上建了哪些通道**。
资源是设备上报的物理事实（只读），通道是用户基于资源创建的采集实例（可写）—— 两者是不同层级，必须分区呈现。

#### 4.6.1 顶部提示与数据加载

| 编号 | 规则 |
|---|---|
| ND-DU-01 | 顶部常驻提示：「仅在线可编辑」。在线文案为「当前设备在线，您可以查看和修改配置」；离线为「当前设备离线，只能查看已上报的资源配置」 |
| ND-DU-02 | 提示条右侧提供「查询资源」：向节点请求重新上报资源，按钮显示「查询中…」；离线或查询中禁用 |
| ND-DU-03 | 首次进入本页签才加载资源；加载中显示骨架，失败显示「总线资源加载失败」＋「重试」 |
| ND-DU-04 | 资源加载与 DMA 加载相互独立：DMA 读取失败不得把整页判为「资源加载失败」 |
| ND-DU-05 | 重新加载后若原选中资源已不存在，自动归位到第一条；页码越界时自动收回 |

| 编号 | 规则 |

| ND-DU-08 | 资源表列：选择、资源名称、引脚、关键参数、状态（可用／禁用）、已挂载通道数、DMA 绑定、操作（查看、新建通道） |

## 5. 业务规则

本节是跨页面、跨页签的稳定规则；需求条目与验收条目都应能追溯到这里的某一条。

### BR-01 节点身份与命名

- 设备 ID 是节点的唯一业务身份：**12 位大写十六进制**（设备 MAC 派生）。页面手动注册时做强校验；展示时按原样保留大小写。
- 展示名回退顺序：名称 → 「节点 设备ID」→「节点 主键」→「未命名节点」。所有位置（列表、详情、删除确认、通道筛选下拉、读屏标签）必须使用同一回退。
- 名称允许为空、允许中文、最长 64 字符；重命名是中心端数据操作，**离线也可执行**。
- 名称不是身份：任何数据关联、跳转、查询都必须使用设备 ID，不得使用名称或数字主键替代。

### BR-02 在线与离线

| 项 | 规则 |
|---|---|
| 判定主体 | 由中心端判定并推送，页面不自行计时、不自行推断 |
| 在线 | 最近一次心跳在 **3 秒**阈值内有效 |
| 离线 | 超过 3 秒无心跳；服务端每秒探测一次 |
| 可见时延 | 节点断电到页面显示离线，最坏约 **5 秒**（1 秒心跳 + 3 秒阈值 + 1 秒探测） |
| 页面行为 | 收到状态变化即时更新页头与指标；离线后连接质量不再展示、实时指标保留最后值并弱化 |
| 不得 | 不得用「最后一次操作的成败」推断在线状态；不得在离线时继续展示「同步中」 |

### BR-03 连接质量

- 取值 0–100，由中心端综合**信号强度与往返时延**计算，页面不重算。
- 四档文案：≥80 优秀、≥60 良好、≥40 一般、<40 较差；颜色依次为绿、蓝、橙、红。
- 仅在线展示。列表用进度条＋百分比（三档配色：≥80 绿、≥60 橙、<60 红）；详情用条形图标＋百分比＋文案。
- 0 是有效值（质量为 0），不是「无数据」；但离线时一律不展示质量。

### BR-04 延迟

- 数据优先级：**最近一次主动测延迟的结果** 高于 设备上报的延迟。
- 0 或缺失视为无数据，显示「—」，不得显示「0 ms」。
- 主动测延迟：下发探测 → 等待结果事件 → 5 秒未到则提示「延迟测量超时，节点可能离线」。
- 详情首次加载时，若节点在线且没有任何延迟数据，自动测一次，避免「在线但延迟永远为空」。
- 列表的延迟列与详情同源（见 G2 的现状偏差）。

### BR-05 在线时长与固件在线时长

| 指标 | 含义 | 计算 | 离线 |
|---|---|---|---|
| 上线时间 | 本次会话开始时间 | 中心端在离线→在线时记录 | 保留最后值 |
| 在线时长 | 本次会话已持续多久 | 当前时间 − 上线时间，每秒刷新 | 「—」 |
| 固件在线时长 | 设备自报的本次运行时长 | 设备上报值格式化 | 「—」 |

两者**不可互换**：在线时长反映「会话」，固件在线时长反映「设备运行」，设备重启后两者会分叉。

### BR-06 配置同步状态

| 状态 | 中文 | 含义 | 颜色 |
|---|---|---|---|
| 已同步 | 已同步 | 配置已生效且与中心端一致 | 绿 |
| 同步中 | 同步中 | 已下发，等待设备回执 | 橙 |
| 同步失败 | 同步失败 | 设备拒绝或应用失败 | 红 |
| 落后 | 落后 | 设备持有的配置版本落后 | 红 |
| 错误 | 错误 | 同步链路或校验异常 | 红 |
| 未知 | 未知 | 尚未同步或数据缺失 | 灰 |

- 离线时**强制显示「离线」**，覆盖上述任何状态（离线节点不可能正在同步成功）。
- 「同步配置」按钮触发后只表示「已下发」；真正的结果要等状态变为「已同步」——当前无实时推送，需刷新确认（G6）。
- 状态文案必须集中维护，不得在页面各处各写一份映射。

### BR-07 配置告警（DMA 降级）

- 语义：**配置成功**，但部分通道从 DMA 降级为中断／轮询，功能正常但性能下降。
- 因此用警告色、与「配置同步」分列；不得把它渲染成配置失败。
- 文案由服务端给出中文，页面原样显示；页面不得自行拼接或翻译。
- 无告警时不渲染该区域；数据缺失或格式异常时静默忽略，不得崩溃或留空白行。

### BR-08 通道健康

- 状态归一：正常＝正常／在线／运行中；异常＝错误／失败／告警；未提供状态按正常计。
- 四个计数与预览列表必须来自同一份数据；「其他」为剩余量。
- 计数是**全量**，列表是**预览**；截断必须显式可见。
- 现网缺口：通道状态没有写入方，全部按正常计（G1）。规则保留，数据接入后自动生效。

### BR-09 能力驱动与层级

| 层级 | 定义 | 来源 | 可写性 |
|---|---|---|---|
| 资源（总线资源） | 设备上报的物理能力：UART／I2C／SPI／ADC／GPIO／PWM | 设备资源上报 | 只读（DMA 绑定除外） |
| 通道 | 建立在某条资源上的采集实例 | 用户创建 | 可增删改 |
| 边缘设备 | 挂在某条通道上的具体设备 | 用户创建 | 可增删改 |
| 外设 | GPIO／PWM 的引脚级配置 | 用户创建 | 可增删改（不走通道） |

- **未上报 ≠ 数量为 0**：设备没上报某类资源时，页面不得声称「该设备没有这种资源」，只能说「未上报该类型资源」。
- GPIO／PWM 是引脚直控，**不得**出现在通道的类型选项里，也不得通过通道接口操作。
- 资源被禁用时，其上不得新建通道、不得绑定 DMA，但既有通道仍需展示。

### BR-10 离线可操作边界

| 动作 | 在线 | 离线 | 说明 |
|---|---|---|---|
| 查看列表／详情／各页签 | 可 | 可 | 离线数据为最后一次上报值 |
| 重命名、复制设备 ID | 可 | 可 | 中心端数据操作 |
| 删除节点 | 可 | 可 | 不要求节点在线 |
| 同步配置、OTA 升级、测延迟 | 可 | 禁用 | 需要设备响应 |
| 重启、恢复出厂 | 可 | 禁用 | 需要设备响应 |
| 新建／编辑／删除通道 | 可 | 禁用 | 需下发配置 |
| 删除通道（通道健康卡） | 可 | 隐藏 | 与上面一致 |
| DMA 绑定、资源查询、I2C 扫描、改波特率 | 可 | 禁用 | 需下发配置或读取设备 |
| GPIO／PWM 配置与读写 | 可 | 禁用 | 需设备执行 |
| 创建设备（关联设备页签） | 可 | 禁用 | 需下发初始化 |
| 取消 OTA | 可 | 禁用 | 服务端本身不要求在线，页面从严 |
| 系统日志开关／清理 | 可 | 可 | 面板不感知在线；离线期间不会产生新日志 |
| 通道终端发送 | 可 | 可 | 不校验在线与使能，属调试工具语义 |

原则：**写操作在离线时要么禁用并说明原因，要么保持可用但由服务端判定并如实反馈**；不允许「点了必然失败却看起来可用」。

### BR-11 危险操作与二次确认

| 动作 | 不可逆程度 | 确认要求 |
|---|---|---|
| 删除节点 | 高（数据软删，页面不可见） | 危险确认，写明名称与不可恢复 |
| 删除通道 | 高（会下发配置变更） | 危险确认，写明通道名与不可恢复 |
| 恢复出厂 | 高（清除设备配置） | 危险确认，写明保留 WiFi 与身份、设备会自动重连 |
| 重启节点 | 中（短暂断连） | 危险确认，写明 10–30 秒后自动重连、配置保留 |
| 取消 OTA | 中（中断升级） | 危险确认 |
| 移除外设配置 | 中 | 危险确认 |
| 清理全部日志／按时间清理 | 高（不可恢复） | 危险确认 |
| 强制升级 | 高（可能装错版本） | 确认升级理由必填，写入审计 |

- 确认方式为**二次点击**，不要求输入密码；破坏性按钮为危险样式，默认焦点落在取消侧。
- 确认文案必须写清后果与影响范围，禁止只写「确定吗？」。

### BR-12 写操作的结果语义

页面必须把结果归入以下五类之一，不得混用：

| 类别 | 触发 | 页面表现 |
|---|---|---|
| 成功 | 服务端明确成功 | 成功提示＋刷新受影响的视图 |
| 未改动 | 目标值与当前一致 | 中性提示「未做改动」，不报成功、不报失败 |
| 结果未知 | 指令已送达但设备未确认 | 警告提示「可能已生效，请稍后刷新，不要直接重复操作」；**不得说失败** |
| 保护性拒绝 | 因引用关系或资源约束被拒绝 | 警告色说明原因与下一步（如先移除引用）；不按故障报红 |
| 失败 | 明确失败 | 错误提示，保留可重试路径；不刷新成假成功 |

### BR-13 上下文隔离与竞态

- 切换节点后：旧节点在途的详情、通道、事件、设备、OTA、能力请求结果全部作废，不得写入新节点。
- 切换节点后：旧节点的外设回填、测延迟结果、DMA 操作结果不得落到新页面。
- 页签切换：不重置已加载数据；补拉只补缺失的那份。
- 重新登录或会话变更后：在途写操作的结果不得再更新界面。
- 同一操作进行中禁止重复提交（按钮进入进行中态并禁用）。

### BR-14 数据新鲜度与缓存

| 数据 | 新鲜度策略 | 页面提示 |
|---|---|---|
| 节点列表 | 短缓存（秒级），可强制刷新 | 手动刷新有成功提示 |
| 节点详情 | 短缓存（秒级），可强制刷新 | 指标区显示「更新于 N 秒前」 |
| 关联设备列表 | 30 秒缓存，进入页签或刷新时重取 | 卡片显示条数 |
| 通道／事件／OTA 历史 | 每次进入详情或刷新时重取 | 各自的加载中状态 |
| 实时指标 | 最后上报值；离线时弱化 | 「离线·最后上报」 |

- 离线状态下的数值一律标注为「最后上报」，不得让用户以为是实时值。
- 缓存不得跨越节点：节点 A 的数据不得在节点 B 的页面短暂出现。

### BR-15 检索、筛选与分页一致性

- 检索与筛选在**服务端**执行，覆盖全库；页面不得对服务端结果再做本地过滤（会造成「筛选只在当前页生效」的假象）。
- 任一筛选变化：页码归 1 并重新请求；两者必须成对出现。
- 统计卡只反映当前页；型号选项只来自当前页；这两点必须在文案上明示（「本页」「当前页出现的型号」）。
- 空结果与请求失败必须区分。

### BR-16 状态、占位与格式

| 项 | 规则 |
|---|---|
| 未知占位 | 统一使用「—」（全角破折号）；不得使用半角连字符；0 与「—」含义不同 |
| 时间 | 绝对时间格式统一为 `YYYY/MM/DD HH:mm:ss`；无效时间（1970／0001）显示「—」 |
| 相对时间 | 刚刚／N 分钟前／N 小时前／N 天前；超过 7 天显示日期 |
| 时长 | 「N天 N小时 N分钟」；不足 1 天省略天，不足 1 小时省略小时 |
| 容量 | 字节转 KB／MB，保留合理精度 |
| 状态文案 | 必须中文；内部枚举不得直接暴露给用户 |
| 颜色 | 颜色只作辅助，状态必须有文字；同一语义在全页使用同一颜色 |

### BR-17 移动端与可访问性

- 断点：768px（移动端）、1200px（窄桌面）、1440px（总线双栏下限）。
- 页头按钮在移动端换行收纳为两列；统计卡在移动端单行四列紧凑显示。
- 宽表（列表、资源、OTA、日志历史）必须提供横滑容器与「左右滑动」提示；关键文字按钮的触控目标不小于 44×44。
- 可点击的卡片、表格行、页签、通道行必须键盘可达（Enter／Space），有可见焦点环与可读的 aria 标签。
- 页签栏在窄屏可横滑，并用两侧渐隐提示还有内容；激活项自动滚入视野，用户必须能看见自己在哪个页签。
- 暗色主题下所有语义色必须有对应暗色值，不得出现「亮色值落在深色底上不可读」。

## 8. 权限、安全与审计

| 项 | 现状要求 |
|---|---|
| 访问控制 | 所有页面与操作要求已登录；未登录跳转登录页并携带回跳地址 |
| 角色分级 | 当前为单主体模式，无角色差异；所有登录用户可执行全部写操作（不隐藏入口） |
| 危险动作确认 | 二次点击确认，不要求输入密码（2026-11-15 裁决）；破坏性按钮默认焦点在取消侧 |

| 敏感信息 | 页面不展示设备密钥、WiFi 密码、令牌；复制设备 ID 属于公开标识 |
| 误操作防护 | 进行中禁止重复提交；危险动作必须写明后果；「结果未知」不得诱导重复操作 |

## 9. 非功能要求

| 类别 | 要求 |
|---|---|
| 首屏 | 列表有缓存时直接渲染；无缓存显示骨架。详情首屏显示骨架，不得先显示「节点不存在」再加载成功 |
| 实时性 | 状态变化 ≤5 秒可见；主动测延迟 ≤5 秒出结果或超时；日志实时推送；在线时长每秒刷新 |

| 可维护性 | 状态文案、占位符、时间格式、名称回退等口径各只有一处权威实现，禁止逐页复制 |

## 10. 验收标准

| 编号 | 场景 | 预期 |
|---|---|---|
| AC-01 | 首次进入节点列表（无缓存） | 显示统计卡与卡片骨架，加载完成后渲染数据，不出现「暂无节点」闪烁 |
| AC-02 | 点击「本页在线」统计卡 | 状态筛选切换为在线、页码回 1、重新请求；筛选标签出现 |
| AC-03 | 关键词输入后快速继续输入 | 只在停止输入 300ms 后发一次请求；清空立即请求 |
| AC-04 | 在第 3 页切换状态筛选 | 页码回到 1，且请求携带新状态参数 |
| AC-05 | 添加节点输入非法设备 ID | 不发请求，提示 12 位十六进制格式与示例 |

| AC-08 | 列表在线节点被断电 | ≤5 秒后该卡片变为离线、质量归零，列表不整体闪烁 |
| AC-09 | 切换每页条数 | 回到第 1 页，按新页长请求 |
| AC-10 | 离线节点详情 | 同步配置／OTA／测延迟／重启／恢复出厂均禁用并提示原因；重命名仍可用 |
| AC-11 | 重命名节点为纯空格 | 拒绝保存并提示名称不能为空 |
| AC-12 | 测延迟设备无响应 | 5 秒后提示「延迟测量超时，节点可能离线」，按钮恢复 |
| AC-13 | 五格字段缺失 | 统一显示「—」，不出现半角连字符或空白 |
| AC-14 | 离线节点配置同步状态 | 强制显示「离线」，不显示「同步中」 |
| AC-15 | 设备上报 DMA 降级告警 | 警告色展示中文告警，配置同步仍显示「已同步」 |

| AC-17 | 删除被边缘设备引用的通道 | 警告色提示需先移除引用；不显示为失败 |
| AC-18 | 切换总线子页签 | 页码回 1、选中第一条资源、清空上一资源的扫描结果 |
| AC-19 | 某资源有 3 条兼容 DMA | 显示下拉选择器，含「不使用 DMA」，选项带编号 |
| AC-20 | 某资源无兼容 DMA | 不留空控件，按三种原因之一给出说明 |
| AC-21 | 单条改波特率失败 | 就地显示错误并保持编辑态；不刷新、不谎报成功 |
| AC-22 | 离线进入外设控制 | GPIO 显示离线提示且写入／读取／配置禁用；PWM 显示最后已知配置 |

| AC-24 | 关联设备处于等待中 | 状态徽标为「等待中」，卡片不变暗 |
| AC-25 | 快速创建设备选了一个无匹配通道的型号 | 提示「该节点暂无匹配 X 的通道，请先在总线配置中创建」，提交禁用 |

| AC-27 | 取消等待中的 OTA | 二次确认后取消成功并刷新历史 |

| AC-29 | 通道终端输入奇数长度 HEX | 提示「无效的 HEX 数据（需偶数长度）」且不发送 |

### 11.2 现状缺口（需求与实现的差距）

以下条目**不是需求**，而是当前实现达不到需求的地方，供产品裁决与排期；页面行为以现状为准，验收时不应把它们当缺陷重复上报。

| # | 现象 | 影响 | 建议 |
|---|---|---|---|
| G1 | 通道状态没有服务端写入方，页面全部按「正常」计 | 通道健康卡只能反映数量，无法发现异常通道 | 接入节点通道健康上报，或由配置校验派生状态 |
| G2 | 列表「延迟」列依赖设备上报的延迟值，而该值当前无人写入 | 列表延迟长期为空，用户误以为列表坏了 | 列表复用最近一次测延迟结果，或隐藏该列 |
| G3 | 「本页告警」统计卡没有对应的节点状态 | 恒为 0，可能被误读为「无告警」 | 定义告警口径（离线超时／配置失败／降级）或隐藏该卡 |
| G4 | 总线配置的 I2C 地址扫描是占位实现，恒返回空 | 现场会得到「未发现设备」的错误结论 | 接线真实扫描，或在入口明确标注「暂不可用」 |
| G5 | 能力接口无法区分「设备未上报 DMA」与「上报了但为空」 | DMA 页签空态可能给出错误归因 | 能力数据增加「是否已上报」标记 |
| G6 | 配置同步完成没有实时推送 | 用户点完「同步配置」看不到结果变化，需手动刷新 | 发布同步完成事件，或页面轮询状态 |
| G7 | 删除节点为软删除且不级联 | 通道／设备／历史仍在，可能在其它页面出现 | 明确产品策略：禁止删除有设备的节点，或级联软删并提示 |
| G8 | 手动注册的服务端校验只有唯一性，无格式校验 | 非页面入口可写入非法设备 ID | 服务端统一做 12 位十六进制校验 |
| G9 | 通道「名称」不会持久化 | 用户命名丢失，列表回退为硬件标识 | 持久化名称，或移除该输入项并说明 |
| G10 | 关联设备一次最多 100 台；通道一次最多 200 条，均无分页 | 巨型节点会静默少显示 | 加分页，或显式提示「已截断」 |
| G11 | 列表搜索不匹配设备 ID | 用户习惯用设备 ID 搜索却搜不到 | 扩展检索字段，或在占位文案中写明只搜名称/型号 |
| G12 | 无批量操作（批量升级／同步／删除） | 大规模运维效率低 | 后续版本支持多选与批量动作 |
| G13 | 节点状态只有在线／离线，页面不展示「已禁用」 | 若服务端出现已禁用状态，会显示为离线 | 明确状态枚举与展示口径 |
| G14 | 列表卡片「升级」离线仍可点 | 可能创建出无法执行的升级任务，或让用户误判 | 与详情页一致：离线禁用，或明确「排队等待上线」 |
| G15 | 列表与表格的离线／无数据占位使用半角连字符，与 BR-16 的「—」不一致 | 跨页占位不统一，削弱「未知」与「0」的区分 | 统一为全角破折号「—」 |

### 11.3 非目标（本页面明确不做）

- 不做节点拓扑图、不做地理分布。
- 不做批量运维编排（批量升级、批量同步、批量删除）。
- 不做设备配置模板（型号定义）的编辑；需要时跳转配置模板页。
- 不做传感器数据的趋势分析与导出；需要时跳转数据面板与边缘设备详情。
- 不提供协议报文构造器；通道终端只做原始字节收发。
- 不在页面内展示或修改 WiFi 凭据、密钥等敏感配置。
