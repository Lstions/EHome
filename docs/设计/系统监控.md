## 1. 功能概述

运行指标页（自动刷新可选 5s/10s/30s），健康检查端点，Prometheus 抓取端点，平台总览 API。

## 2. 端点

| 端点 | 用途 |
|------|------|
| /metrics | JSON 业务指标（前端监控页数据源） |
| /metrics/prometheus | Prometheus 抓取（ehome_* 15+ 族） |
| /health | 健康检查 |
| /overview | 平台总览（统计聚合 + 异常摘要 + 趋势分类） |

## 3. 指标

### 3.1 业务指标（/metrics，前端卡片）

- 节点在线/离线/总数。
- 边缘设备总数（按状态）。
- 数据接收计数/速率。
- 能力快照超期节点数（ResourceReport 超过有效期未上报的节点——健康指标）。
- 同步在途数、告警活跃数（v3.4）。

### 3.2 Prometheus 指标族（核心）

| 指标 | 含义 |
|------|------|
| ehome_node_online_count | 在线节点数 |
| ehome_data_received_total | 数据接收计数 |
| ehome_sync_decisions_total | 同步决策（reason/action） |
| ehome_sync_duration_seconds | 同步耗时 |
| ehome_config_epoch | 当前配置 epoch |
| ehome_event_bus_dropped_total | 事件总线丢弃 |
| ehome_edge_device_total | 边缘设备数（status） |
| ehome_https_ota_failures_total | OTA 失败（reason） |

## 4. 容错设计

- 监控页数据源失败：显示错误态 + 重试，不影响其他页面。
- 自动刷新暂停：页面不可见时停止轮询，返回时恢复（避免空轮）。
- 指标聚合 Go 侧完成（不压 DB）。

## 5. 前端

- views/monitor/Monitor.vue：指标卡 + 自动刷新选择器（5/10/30s）+ 健康状态区。
- 卡片规范：透明底 + tone 图标（遵守前端规范 §4.3 统计卡）。
