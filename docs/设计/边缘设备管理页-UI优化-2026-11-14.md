## 1. 原流程与控件盘点

~~~text
/edge-device
  ├─ 范围切换：在役设备 / 历史设备（scope-tabs + 长说明）
  ├─ 统计：本页设备 / 在线 / 离线异常(含等待数据) / 今日采样帧
  ├─ 工具栏：搜索、设备类型、状态、硬件类型、视图切换、批量管理、
  │          恢复已删除设备、创建边缘设备
  ├─ 当前筛选 chips + 清除全部
  ├─ 批量条（卡片模式勾选 / 表格勾选）：启停、采集间隔、全选、取消、删除、导出
  ├─ 列表：卡片网格（默认）/ 表格；分页 12/24/48
  ├─ 历史设备面板：恢复 / 彻底删除 / 导出
  └─ 弹窗：创建/编辑向导、删除、批量删除、恢复、合并历史、批量间隔
~~~

| 控件 | 作用 | 约束/联动 |
|---|---|---|
| 范围切换 | 在役 / 历史 | 历史设备为软删且数据保留；彻底删除不可恢复 |
| 统计卡 | 本页设备、在线、离线+等待、今日采样帧（全局） | 4 卡契约（移动端也是 4 列）；点击可下钻筛选 |
| 搜索 | 名称/类型/中文类型 | 防抖，服务端 `search` 参数 |
| 类型/状态/硬件筛选 | 缩小列表 | 写入 URL 查询、重置分页 |
| 视图切换 | 卡片 / 表格 | 批量管理仅卡片模式 |
| 批量管理 | 卡片上出现复选与批量条 | 与表格选择集共用 `selectedDevices` |
| 恢复已删除设备 | 打开恢复弹窗 | 历史视图也可操作 |
| 创建边缘设备 | 打开 3 步向导 | 空态也应有入口 |
| 卡片操作 | 详情/编辑/合并历史/删除 | 删除为软删；合并仅同型号历史设备 |
| 批量条 | 批量启停/间隔/删除/导出 | 选择为空时隐藏 |

## 3. 重设计

### 3.1 工具栏（核心）

- **桌面**：单行。搜索 240px（可伸缩）+ 三个筛选 + 视图切换 + 批量开关 +
  恢复 + 创建；高度 98 → **66px**。
- **移动端**：
  - 第一行：搜索（占满剩余）+「筛选」按钮（显示生效筛选数徽标）；
  - 第二行：视图切换（图标组）+ 批量开关（文案缩为「批量」）+「更多」菜单 +
    「新建」主按钮；
  - 三个筛选下拉收进**底部抽屉**（与桌面共用同一批 `v-model`，不复制逻辑）；
  - 工具栏高度 330 → **120px**，第一张卡片 641 → **385px**。
- 「更多」菜单：恢复已删除设备 / 刷新列表（桌面仍是独立按钮）。

### 3.2 卡片与操作

- 操作按钮桌面 **32px**、移动 **44px**；
- 移动端只保留图标（详情保留文字），`aria-label` 保留可访问名；
- 四按钮单行排列（详情左、其余右），不再换行挤压卡片高度。

### 3.3 空态

- 主 CTA 改为**创建边缘设备**（打开本页向导），次 CTA 保留「查看节点」；
- 有筛选时文案改为「当前筛选条件下没有设备，试试清除筛选」；
- 无筛选时说明「创建后即可查看实时数据与历史」。

### 3.4 批量条

- 桌面：`position: sticky; top: 8px`，滚动时仍可操作；
- 移动端：`position: fixed` 底部浮层（高 88px），页面加 88px 底部 padding，
  不遮挡最后一张卡片；操作横向可滚动。

### 3.5 其他

- 移动端隐藏长范围说明（`scope-hint`），把空间让给列表；
- 统计卡保持 4 列契约不变；
- 历史视图、批量、分页、弹窗语义不变。

## 4. 实现

- `EdgeDeviceList.vue`：工具栏重构、筛选抽屉、移动「更多」菜单、空态 CTA、
  卡片操作图标化、批量条吸顶/浮动、响应式 CSS；
- 新增状态：`mobileFiltersVisible`、`activeFilterCount`、`activeBatchBar`、
  `onMobileMoreCommand`；`useResponsive` 提供 `isMobile`；
- 术语门禁：筛选抽屉标签用「类型」而不是复制「设备类型」，避免术语登记簿计数漂移。
