# 设备 — 验收标准

## 一、前端验收

### 1.1 设备列表
- [ ] 卡片/表格双视图
- [ ] 4 个统计卡 (总数/在线/离线/今日数据)
- [ ] 关键词搜索 (设备名)
- [ ] 类型/状态/硬件筛选
- [ ] 批量删除 (operator+)
- [ ] 批量导出 CSV
- [ ] 卡片显示: 设备名/类型/采集器/状态/最新值/采集间隔

### 1.2 创建设备向导 (3 步)
- [ ] Step 0: 选解析器 + "使用配置模板"可选下拉 (套用 device_type/hardware_type/protocol/parser)
- [ ] Step 1: 选采集器 + 已有通道 / 创建新通道 (I2C 地址扫描)
- [ ] Step 2: 设备名 + 采集间隔 + 预览
- [ ] 模板套用后绿色提示条显示 "已套用模板"
- [ ] 选模板后自动选对应解析器

### 1.3 设备详情
- [ ] 顶部状态卡: 设备名/状态/通道/最新数据/错误码徽章
- [ ] 实时数据列表 (HEX/明文切换, 虚拟滚动)
- [ ] 历史数据图表 (LineChart, 多 series, 1h/24h/7d 范围)
- [ ] 历史数据表格 + CSV/JSON 导出
- [ ] 操作按钮 (按 device_type 动态生成)

### 1.4 设备操作
- [ ] 雨量: 重置按钮 + 二次确认
- [ ] GPIO digital: 高/低/翻转按钮
- [ ] GPIO PWM: 滑块 + 输入数值
- [ ] 电池: 重启按钮
- [ ] 操作日志 (按时间倒序, 成功/失败标记)

## 二、后端验收

### 2.1 端点
- [ ] `GET /api/v1/devices` 列表 (分页 + 过滤)
- [ ] `GET /api/v1/devices/:id` 详情
- [ ] `POST /api/v1/devices` 创建
- [ ] `PUT /api/v1/devices/:id` 更新 (device_type/protocol 不可改)
- [ ] `DELETE /api/v1/devices/:id` 删除
- [ ] `GET /api/v1/devices/:id/latest-data` 最新数据
- [ ] `GET /api/v1/devices/:id/data?start=&end=&page=&page_size=` 历史数据
- [ ] `POST /api/v1/devices/:id/operations` 远程操作

### 2.2 数据模型
- [ ] 11 字段 + 3 索引
- [ ] AutoMigrate 自动建表
- [ ] last_data JSONB 自动序列化
- [ ] 软删除 (P3 计划)

### 2.3 操作 (WriteCommand)
- [ ] WriteCommand 正确编码 (字段顺序, 长度)
- [ ] WriteResponse 30s 内未回 → 超时错误
- [ ] 操作日志记录 (含 success + latency)
- [ ] 同一设备操作串行化 (worker pool)

### 2.4 数据聚合
- [ ] 设备 10min 无数据 → status=offline
- [ ] 解析失败 → error_code 标记 + notification
- [ ] 采集间隔 < 100ms 拒绝
- [ ] last_data 自动更新

## 三、采集器端验收

### 3.1 DataReport
- [ ] 按 device.interval_ms 定时触发
- [ ] raw_data 正确 (按 channel 类型)
- [ ] parsed_data 正确 (按 parser)
- [ ] mqtt.up 发送成功
- [ ] 错误码正确填充 (HAL 错误码 0-8)

### 3.2 写命令处理
- [ ] 收到 WriteCommand → 解析 op_type
- [ ] 按 device_type 处理 (PWM/雨量/GPIO)
- [ ] 30s 内发 WriteResponse (success/failure)
- [ ] 操作失败填 error_msg

### 3.3 状态机
- [ ] 60s 内无数据 → collector 仍 online (设备级 offline P3)
- [ ] error_code != 0 持续 5min → 推 notification
- [ ] 恢复后正常数据 → 错误清零

## 四、集成验收

### 4.1 端到端
- [ ] 创建设备 → ESP32 收到 ConfigManifest → DataReport 上报
- [ ] 前端实时列表看到新数据
- [ ] 触发 PWM 50% → ESP32 设置成功 → WriteResponse success
- [ ] 操作日志显示
- [ ] 关闭 ESP32 → 10min 后 status=offline + notification
