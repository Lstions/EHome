## 1. 本规范约束什么

**约束范围**：设备上报数据在"名字 / 单位 / 值类型 / 聚合 / 别名 / 派生"六个维度上的定义、使用与变更。

**不约束**：协议帧格式（见 [协议](../协议/二进制帧协议.md)）、实体模型（见 [概念模型](概念模型.md)）、存储/分区（见 [数据采集与数据链路](数据采集与数据链路.md)）。

**为什么需要它**：治理评估实测——数据语义层此前**零规范**：字段名在 5 处各写一遍、4 个"词表候选"全空或孤儿、前端标签覆盖率 46%、unit 语义重载（ack/raw/state/bitmask 当单位）、列宽 32/64 混用、CI 零门禁。结果是"配置错了不报错、规则永不触发也没人知道"。

## 2. 数据类别（Data Category）命名规范

### 2.1 文法（强制）

数据类别必须匹配：小写 ASCII 字母开头，随后是小写字母/数字/下划线，长度不超过 64 字符（按字符计）。

| 规则 | 值 |
|---|---|
| 字符集 | 仅小写 ASCII a-z、数字 0-9、下划线 _ |
| 首字符 | 必须是字母 |
| 长度 | 不超过 64 字符（**字符数**，非字节）；DB 列统一 VARCHAR(64) |
| 大小写 | **大小写敏感**；出现大写即非法（不静默转小写） |
| 保留字符 | 不得包含 @、:、*、空格（这些是选择器语法字符） |

### 2.2 动态族命名

族 = 前缀 + 下划线 + 数字后缀。

- 族成员由设备上报决定（如 cell_count=16 则有 cell_voltage_1..16），**不可穷举**，因此**禁止**在文档/配置里逐个枚举族成员作为词表。
- **不等于**前缀匹配：cell_voltage_* **只匹配** cell_voltage_<数字>，**不匹配** cell_voltage_max/min/avg（后者是派生归约量，不是测点）。
- 序号按**数值**排序（`_10` 在 `_2` 之后），不按字典序。

### 2.3 禁止的名字

| ❌ 禁止 | ✅ 替代 | 理由 |
|---|---|---|
| temperature（同时用作族与单点） | temperature_1 + 语义名 @temperature | 单点/族歧义 |
| power（交流/直流/总功率不分） | dc_power / ac_power / total_power | 物理量歧义 |
| status / state（无对象） | protection_status / fet_status | 无主语 |
| 回执/控制量混入数据类别 | 保留在动作回执（*_ack），**不落 unified_data** | 语义污染（现网 6 个 *_ack 伪量属历史遗留） |

## 3. 单位（Unit）规范

### 3.1 受控白名单

| 类别 | 允许值 |
|---|---|
| 电学 | V、mV、A、mA、Ah、mAh、W、kW、kWh、VA、mΩ、Ω |
| 温度 | °C |
| 比例/计数 | %、次、串、h、s、天 |
| 其它物理量 | mm、hPa、lx、dB、ppm、m/s、Hz、°、bit/s |
| 无量纲/未标注 | **空串**（合法；表示"无单位"） |

**归一规则**：%RH → %；Lux → lx；空格+C → °C。

### 3.2 单位不得承载"值类型"

ack / raw / state / bitmask **不是单位**，禁止写入 unit 列。值类型由 §4 的 value_type 表达。

> 现状：现网驱动里仍有约 27 处（12 ack / 8 bitmask / 5 raw / 2 state）。这些是**待迁移技术债**，新增代码禁止再写。

## 4. 值类型（Value Type）规范

| value_type | 含义 | 参与数值比较 | 展示 |
|---|---|---|---|
| number | 连续数值 | 是 | 按 precision 格式化 |
| boolean | 0/1 语义 | 否（视为缺失） | 开/关 |
| enum | 枚举码 | 否 | 码表映射 |
| bitmask | 位域 | 否（eq 是整字相等而非位测试，易误用） | 位图 |
| string | 字符串（版本号/序列号） | 否 | 原样 |
| raw | 未解释 | 否 | 十六进制 |

**默认**：未标注时按 number 处理（兼容存量），但**解析层对非 number 的字段在数值聚合中一律视为"本帧缺失"**（fail-closed）。

## 5. 聚合（Aggregate）规范

### 5.1 六种聚合

| 聚合 | 语义 | 空集 | 本帧缺"已知成员" |
|---|---|---|---|
| any（默认） | 存在某字段满足 | unbound | 不受影响 |
| all | 全部字段满足 | unbound（**不采用空真**） | unbound |
| min / max / avg / sum | 先归约再比较 | unbound | unbound |

### 5.2 前置定义（不可省略）

1. **有效值**：有限数（非 NaN、非 ±Inf）。否则该字段视为"本帧缺失"。
2. **已知集合 vs 本帧集合**：聚合以**本帧集合**求值；但 all/min/max/avg/sum 在**本帧缺失任一已知成员**时判 unbound（不触发）。
   - 理由：BMS 探头数随帧变化是真实场景；只看本帧的 all > 45 会漏掉已知的第 3/4 个探头，方向危险。
3. **空集**：全部聚合 unbound（尤其 sum=0 会让 sum < 10 **反向触发**）。
4. **reducer + neq**：语义陷阱（几乎恒真），保存期给警告，不推荐。

### 5.3 真值表要求

实现必须有 **6 聚合 × 6 比较符 × 6 场景（空集/单元素/齐全/缺员/含 NaN/非数值）= 216 格**逐格断言。只测 36 格（齐全场景）不算覆盖。

## 6. 别名与派生规范

### 6.1 别名（跨厂商归一）

- **唯一一份配置**：config/field_aliases.yaml，按 key **整体替换**（不追加）。
- 每个语义名必须声明 expected_unit；候选单位类不符 ⇒ **启动失败**。
- 同一物理名出现在多个语义名下 ⇒ **启动失败**，除非显式 allow_overlap: true。
- 候选必须有序；首个命中优先；**非首候选/多候选同时存在**时：冻结首次解析 + 触发前一次性通知 + UI 展示实际物理名。
- **禁止死候选**（驱动不产出的名字）；启动期由 Validate 检出。

### 6.2 派生（virtual）

- 只允许受限函数：product / sum / diff / abs_diff / ratio / scale / max_of / min_of / sum_of；**不引入表达式语言**。
- 任一输入缺失 ⇒ 整体 unbound（**不 fallback 0**）。
- 输出非有限（NaN 或 ±Inf）⇒ unbound + 指标。
- 嵌套深度不超过 4；禁止环（启动期拓扑排序）。
- 命名必须带物理限定（dc_power / ac_power，不用 power）。

## 7. 存储与列宽

| 位置 | 列 | 类型 | 说明 |
|---|---|---|---|
| unified_data | sensor_name | VARCHAR(64) | 数据类别 |
| unified_data | unit | VARCHAR(16) | 受控白名单 |
| alert_rules / automation_rules | sensor_name / trigger_sensor_name | VARCHAR(64) | **选择器**（不只是数据类别） |
| data_sources / data_source_health / failover_logs | category | VARCHAR(64) | 一期只支持字面量（见方案 §9.4） |

**纪律**：全链列宽统一 64；写入前校验长度，不依赖 DB 报错（超长会让整帧入库失败）。

## 8. 变更流程

| 变更类型 | 要求 |
|---|---|
| 新增数据类别 | 驱动声明（GetSensorDefinitions）或首次观测自动登记；**不改中心端代码** |
| 重命名数据类别 | **禁止原地改**（历史数据不可回溯）；新增 + 旧名标 deprecated + 显式迁移脚本 |
| 改单位 | 必须同时改 value_type 或换算说明；跨单位换算不允许隐式发生 |
| 新增语义名 | 只改配置文件 + 重启；启动期冲突检测必须通过 |
| 新增派生量 | 只改配置 + 重启；参数/环校验必须通过 |

## 9. 门禁（CI）

见 [数据字段解析层-方案](数据字段解析层-方案-2026-10-21.md) §12.3 的 10 条，脚本 backend/scripts/check_field_semantics.sh。核心三条：

1. **数据面零依赖**：internal/databus 不得 import sensorfield。
2. **声明自洽**：驱动声明 ⊆ 产出可达集（防"幽灵传感器"）。
3. **产出可寻址**：所有数据类别匹配 §2.1 文法。

> 门禁对"未实现"的检查项必须 **SKIP 并显式打印**，**不得默认通过**（防假绿——本仓已有教训）。

## 10. 存量处置（M0）

升级前必须对存量值分类（脚本见方案 §4.4）：

| 类别 | 判据 | 处置 |
|---|---|---|
| literal | 匹配 §2.1 文法且非选择器形态 | 原样保留，行为不变 |
| special | 匹配 @x / prefix_* / virtual:x | 标记 needs_review，**不自动生效** |
| legacy | 两者都不匹配 | 按精确字面量匹配（与历史一致），报警并禁止编辑直到迁移 |

**0 行不能证明无风险**：当前库三张规则表均为 0 行，但其他部署可能有值。
