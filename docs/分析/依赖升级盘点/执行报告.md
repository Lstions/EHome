### 3.2 TypeScript 7 为何仍未升（关键结论）

**TS 7.0.2 会让 `vue-tsc` 直接崩溃**：

```
Error [ERR_PACKAGE_PATH_NOT_EXPORTED]:
  Package subpath './lib/tsc' is not defined by "exports"
      at resolveTscPath (vue-tsc/index.js:73:43)
```

已独立验证：TS 7.0.2 的 `exports` 只有 `.`、`./unstable/*` 等，**不含 `./lib/tsc`**（虽然文件物理存在于 `lib/tsc.js`，但未导出）。

**天花板是 TS 6.0.3**，本次已升到该版本并全部验证通过。等 vue-tsc 支持 TS 7 的 API 后再升。
