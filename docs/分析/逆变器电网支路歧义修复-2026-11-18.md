# 逆变器电网支路「接入 ≠ 供能」修复（2026-11-18）

> **状态**: 已实现 + 沙箱视觉验证通过
> **范围**: 逆变器详情页「功率流向」的电网支路；不改协议/后端
> **证据**: [桌面电池模式](../验证/证据-2026-11-18-逆变器电网支路-sandbox/desktop-grid-battery.png) · [桌面市电模式](../验证/证据-2026-11-18-逆变器电网支路-sandbox/desktop-grid-line.png) · [窄屏电池模式](../验证/证据-2026-11-18-逆变器电网支路-sandbox/mobile-grid-battery.png) · [窄屏市电模式](../验证/证据-2026-11-18-逆变器电网支路-sandbox/mobile-grid-line.png)

## 0. 用户诉求

> 「在已连接电网、但是没有使用电网（比如电池模式）工作下，功率流向图电网与 PV 一样绿色指向逆变器有歧义。」

> 「市电模式：肯定会用到电网的，不能用不确定状态描述。」

截图工况：`work_mode=3 电池 Battery`、`grid_voltage=234.8V`、`PV=750W`、`负载=175W`、`电池 51.6V/74%`、`充电 5.0A`。

## 1. 结论

电网支路必须由 `work_mode` 决定，不能只看电压：

- **电池模式**：市电已接入但不参与供能 ⇒ 灰色虚线、无箭头、节点标「未使用」；
- **市电模式**：按拓扑市电必然供电 ⇒ 绿色实线、绿色箭头、节点标「供电」，不再使用任何不确定性标记；
- **待机 / 故障 / 关机 / 模式未知**：无法证明方向 ⇒ 灰色虚线、无箭头，按状态标「待机」或「不可判定」。

## 2. 根因

| 层 | 改前行为 | 问题 |
|---|---|---|
| 纯函数 | `gridFlow(voltage)` 只看电压 | 电池模式无法区分「接入」与「供能」 |
| 组件 | `workMode` 只用于中心标签 | 判定链路没有消费工作模式 |
| 视觉 | 电网与 PV 共用 success 绿实线/箭头/节点 | 电池模式被误读成「电网在供电」 |
| 中间版本 | 市电模式也被标成不确定状态 | 市电模式必然使用电网，不符合实际 |
| 测试 | `BASE` 用 `workMode:3` + `gridVoltage:231.5` 却期待电网箭头 | 契约本身固化了缺陷 |

## 3. 改动

### 3.1 `powerFlow.ts`：判定单一事实源

[powerFlow.ts](../../frontend-shared/src/views/edge-device/inverter/powerFlow.ts#L111-L170) 的 `gridFlow(voltage, workMode)` 按模式返回：

| work_mode | connected | dir | status | 说明 |
|---|---|---|---|---|
| 无电压 | false | none | 未接入 | 不画箭头 |
| `2` 市电 Line | true | in | 供电 | 市电必然供电，直接画能量流 |
| `3` 电池 Battery | true | none | 未使用 | 接入但不参与供能 |
| `1` 待机 Standby | true | none | 待机 | 方向不判定 |
| 其它/未知 | true | none | 不可判定 | 不猜方向 |

`BranchFlow` 不再保留不确定性字段；`GridStatus` 为 `未接入 / 未使用 / 供电 / 待机 / 不可判定`。

### 3.2 `InverterPowerFlow.vue`：按状态配色

- 市电模式复用 `on` 绿色实线 + `pf-arrow-flow` 绿色箭头 + 绿色节点，节点标「电网 · 供电」；
- 电池/待机/未知模式使用 `is-idle` 灰虚线、无箭头；
- 未接入使用 `is-off` 更淡点线、无箭头；
- 状态徽标贴在「电网」标签后，不再放在 PV 数值下方；
- 图例改为「实线 = 能量流；灰色虚线 = 已接入未使用」；
- 窄屏 DOM 用右上角 `pfm-status` 徽标 + 独立箭头 `↓/·`；
- aria-label 电池模式念「已接入，未使用」，市电模式念「流入逆变器」。

关键位置：[电网节点](../../frontend-shared/src/views/edge-device/inverter/InverterPowerFlow.vue#L98-L103)、[电网连线](../../frontend-shared/src/views/edge-device/inverter/InverterPowerFlow.vue#L140-L142)、[图例](../../frontend-shared/src/views/edge-device/inverter/InverterPowerFlow.vue#L149-L158)、[判定](../../frontend-shared/src/views/edge-device/inverter/InverterPowerFlow.vue#L245-L249)。

### 3.3 离线验证页

[MockPowerFlowPanel.vue](../../frontend-shared/src/dev/MockPowerFlowPanel.vue#L80-L111) 从四工况扩展到八工况，新增：

- ⑤ 电池模式：市电接入但未使用（复刻 2026-11-18 截图）
- ⑥ 市电模式：市电供电
- ⑦ 市电未接入
- ⑧ 待机：市电接入，方向不可判定
