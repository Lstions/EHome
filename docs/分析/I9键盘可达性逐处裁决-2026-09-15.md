## 3. 逐处裁决明细

> 判定原则（为免口径漂移，此处显式声明）：
> - **A**：该 `@click` 挂载的**具体动作**（弹窗 / 导航 / 选择 / 写剪贴板）在整条键盘路径上都到不了；
> - **D**：该动作的**目标**已有可聚焦入口（原生 `button`/组件 `el-button`/`role=tab` 的可聚焦 Tab 栏/侧栏 `el-menu` 项），或当前页面本身就是该目标，故重复入口属"鼠标增强"；
> - **B**：`StatCard` 组件自身在 `attrs.onClick` 存在时会注入 `role="button"` + `tabindex="0"` + `aria-label` + `@keydown.enter/space`（见 §3.1 证据），扫描器不认组件语义；
> - **C**：`@click.stop` 的唯一语义是阻止冒泡到父级动作，元素自身不产生任何动作。

### 3.1 B 类的组件证据（`StatCard`）

`frontend-shared/src/components/common/StatCard.vue` 第 2–11 行（原文）：

```vue
<div
  class="stat-card"
  :class="{ clickable: isClickable }"
  v-bind="attrs"
  :role="isClickable ? 'button' : undefined"
  :tabindex="isClickable ? 0 : undefined"
  :aria-label="isClickable ? `查看${label}` : undefined"
  @keydown.enter.prevent="handleKeyboardActivate"
  @keydown.space.prevent="handleKeyboardActivate"
>
```

第 43–53 行：`const isClickable = computed(() => Boolean(attrs.onClick))`，`handleKeyboardActivate` 会把键盘事件转发给 `attrs.onClick`（支持数组与函数）。第 74–77 行还有 `:focus-visible` 3px 焦点环。

⇒ 凡命中项标签是 `<StatCard ... @click=...>` 的，**扫的是组件的使用点、真正的宿主 `<div>` 在运行时已带全套可访问性属性**，属典型「扫描器不认组件语义」的假阳性。

### 修复建议（只给建议，本轮不改源码）

1. **优先做真正的 `<button>`，而不是给 `<div>` 补 ARIA。**
   - 卡片/标签这类"可点区域"，若结构允许，改成 `<button type="button">` 或 `<el-button text>`，可一次性拿到焦点、Enter/Space 激活、`:focus-visible` 焦点环与正确语义，比手写 `role="button" tabindex="0" @keydown.enter.space.prevent` 更不易漏。
   - 参考本仓已有的正确写法：`DeviceControlPanel.vue:8`（`role="button" tabindex="0" @keydown.enter.space.prevent`）、`EdgeDeviceList.vue:218-227`（`copyable` 的 role/tabindex/aria-label/keydown 四件套）、`NodeOverview.vue:119-133`（Tab 栏 `role="tab"` + Enter/Space）。

2. **选择类语义（P0-1 / P0-2 / P3-10）优先用 `el-radio-group` + `el-radio` 或 `listbox` 语义**，而不是给 `div` 补 `role="button"`：它们是"从 N 选 1"，`role="button"` 会让屏幕阅读器读成"按钮"而非"选项"，且丢失已选状态。建议：
   - 卡片保留视觉，内部放 `<el-radio :value="parser.id">` 隐藏原生控件（或用 `role="radio"` + `aria-checked` + roving tabindex 的方向键导航）；
   - 这样"当前选中项"可由 `aria-checked` 表达，扫描器也认。

3. **成对动作合并修**（避免改一处漏一处）：重命名在 `NodeOverview.vue:30`/`:147` 各一处、复制在 ``:47`/`:148` 各一处、通道编辑在 `NodeDetail.vue:284` 与 `ChannelPanel.vue:82` 各一处 —— 建议抽一个小组件（如 `IconAction`）承载"图标按钮 + aria-label + role + tabindex + keydown"，六处一起替换。

4. **给图标按钮强制 `aria-label`**：A 类里 5 处是纯图标（重命名 ×3、复制 ×2），即便补了 tabindex，没有可访问名对屏幕阅读器仍不可用；注意 `NodeOverview.vue:221` 的"最近事件"卡片标题里就有一个**同形但不可点**的 `<span class="card-title">`，靠位置无法区分，必须给名字。

5. **D 类不要动**，但要防回归：D 之所以"可接受"是因为等价入口存在。若将来删掉 `NodeOverview.vue:72` 的「刷新」按钮、或把 `EdgeDeviceList` 的视图切换/行内「查看」按钮去掉，D 会立刻退化成 A。建议在相关组件测试里加一条"等价入口存在"的断言。

6. **建议加静态门禁**（可选）：本轮的 Python 口径可直接做成 `npm run` 检查脚本，但必须**允许组件白名单**（`StatCard` 等自处理组件），否则会持续产出 §3.1 那种假阳性。
