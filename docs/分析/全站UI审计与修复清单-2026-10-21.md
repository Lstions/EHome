# 全站 UI 审计与修复清单（2026-10-21）

审计范围：**全部 20 个页面**（登录 + 19 个业务页），生产环境 `http://100.64.0.7:18090`，真实账号与真实数据。
视口：393×851 dpr2（主力，明色全页 + 暗色抽查）、1440×900（桌面回归）；主滚动容器为 `main.el-main.main-content`。

## 审计方法与口径（重要）

- 截图分段必须滚 **`main.scrollTop`**，不是 `window.scrollTo`（窗口本身不滚；早期一次全站截图因此全部是首屏重复，已作废重拍）。
- 自动量化：每页测 `mainScroll / 页面横向溢出 / 文本截断 / 低对比度（WCAG 公式，含 rgba 正确合成与禁用态豁免）/ 小触控目标 / console 错误`。
- 人工精读：3 个审计组按页分组、逐页滚动截图（每页最多 8 段）+ 弹窗/筛选/空态/暗色/桌面逐一验证，每条缺陷附截图名 + 实测数字 + 源码 `文件:行`。
- 排除口径：禁用态控件对比度（WCAG 豁免）、Element Plus 隐藏 radio、分页器 36px（项目密集列表既有约定）、行内 36px 按钮（F6/F27 已裁决档位）。
