## 1. 路由与页面骨架

| 页面 | 路由 | 组件 |
|------|------|------|
| 节点列表 | /node | views/node/NodeList.vue（约 909 行） |
| 节点详情（旧） | /node/:id | views/node/NodeDetail.vue（约 1248 行） |
| 节点总览（新） | /node/:id/overview | NodeOverview.vue（7 TAB） |

注意：`/node/:id` 仍指向旧版 NodeDetail；新版 6 TAB 总览页路由是 `/node/:id/overview`。

## 2. 节点列表页（NodeList）

- 顶部 4 张 StatCard（总数/在线/离线/边缘设备数，点 KPI 有钻取语义才可点）。
- 工具栏：搜索、筛选、视图切换（卡片/表格）、新建。
- 卡片视图（默认）：状态徽标、名称、型号、固件版本、上线时间。
- 表格视图：同数据双视图，切换保持筛选/分页。
- 空态：无节点引导创建。
- 删除：确认弹窗（对象身份 + 影响说明）。

**重设计必读交互契约**：

1. 节点在线状态由后端判定（90s 心跳离线），前端只展示，不自行推断。
2. "上线时间 + 在线时长"必须与当前时间相容（数据一致性自检）。
3. 刷新只锁刷新控件；表格行操作只锁该行。
4. 移动端 ≤768px：4 张统计卡单行 4 列紧凑横排（禁止恢复 2×2 或单列纵向堆叠）。

## 3. 节点详情 / 总览页（NodeDetail / NodeOverview）

### 3.1 旧版 NodeDetail 能力

- 基本信息卡 + 通道列表 + 关联设备表 + OTA 历史（均走 mobile-table-wrapper 宽表格模式）。
- 面包屑：列表 → 实体名称。
- 设备加载防竞态：collector 就绪后由序列号查询通道/设备（数字主键 route.params.id 不能直接当 node_id 用）。

### 3.2 新版 NodeOverview（7 TAB）

| TAB | 内容 |
|-----|------|
| 基本信息 | 实体身份/状态/操作 |
| 总线配置 | I2C/UART/SPI/ADC 子 Tab（`.bus-subtab` 类）+ GPIO 资源 + 通道管理 |
| DMA 通道 | 只读资源视图（编号/类型/能力/最大突发/绑定/兼容总线） |
| 关联设备 | 列表/卡片双视图（该节点下边缘设备） |
| OTA 历史 | 历次升级记录 |
| 系统日志 | Log V2 实时 + 持久化配置 |
| 通道终端 | WebSocket 透明管道入口 |

**重设计必读易错点（12 条核心）**：

1. 总线配置 TAB 的协议子 Tab DOM 类名是 `.bus-subtab`（不是 .bus-type-tab），激活态带 active class。
2. DMA 绑定是总线配置 TAB 内的行内 el-switch，不是独立编辑表单。
3. 资源表格数据必须等于 ResourceReport 上报——中心端零硬编码，前端不许补默认资源。
4. GPIO/PWM 行未绑定 DMA 时绑定列显示 "—"。
5. I2C 扫描、ping、配置同步是真实 API；部分节点级操作（UART reconfigure）当前是 stub（仅弹警示）。
6. 节点离线时：全部写操作禁用并提示原因；只读内容仍可读。
7. 关联设备 TAB 数据与 edge-device 列表同源，口径一致。
8. 序列号（node_id）与数字主键不是一回事（见 3.1 防止竞态契约）。
9. 日志 TAB 空态与未开启态是两种状态（引导开启持久化）。
10. 移动端宽表格用 `.mobile-table-wrapper` + `.mobile-table-hint`。
11. 视口过窄时（如截屏只有部分子 Tab）先扩视口再验收，不要断定"缺 Tab"。
12. 新页面必须带 PageHeader + 面包屑 + 空态/加载态/错误态三分。

## 4. 数据源契约

- 节点列表/详情：nodes API + node_status WS 事件。
- 通道/设备：channels/edge-devices API（用 node_id 序列号查，非数字 id）。
- 资源：query-resources / capabilities API。
- 状态历史：status-history API。
