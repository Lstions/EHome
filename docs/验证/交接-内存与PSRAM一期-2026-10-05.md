**MemReport(0x20) 实机 MQTT 解码**（订阅 `nodes/F0F5BDFFFE02/up`）：

### task-8 的三个硬发现（必须带进实现）
1. **SoftAP 链接地雷**：`components/wifi_mgr/wifi_mgr.c:110` 无凭据时调 `wifi_mgr_start_provisioning()` → `esp_netif_create_default_wifi_ap()` 在 `SOFTAP_SUPPORT=n` 时**未定义引用**；默认 SSID `"ABC"` 把它掩盖了。**验收硬条件**：`CONFIG_COLLECTOR_WIFI_SSID=""` + `SOFTAP_SUPPORT=n` 必须构建通过。
2. **IPv6-only 缺口**：`wifi_mgr.c:544` 只注册 IPv4 `IP_EVENT_STA_GOT_IP`，未注册 `IP_EVENT_GOT_IP6` → IPv6-only/SLAAC 场景不进 CONNECTED，MQTT supervisor 不启动。
3. **s3p 特殊性**：`STATIC_RX=6` 在 s3p 上编译失败（IDF 把 `RX_BA_WIN` 抬到 16，`2*6<16`）；s3p 的 TX 走 STATIC，`DYNAMIC_TX_BUFFER_NUM` 符号不存在。

## 7. 关键事实速查（接手前必读）

1. **PSRAM mode 是编译期选项**：`CONFIG_SPIRAM_MODE_OCT=y`（开发板型号未确认，先用 OCT 40M，boot log 验证）。
2. **`SPIRAM_IGNORE_NOTFOUND` 必须 =n**：否则 `SPIRAM_TRY_ALLOCATE_WIFI_LWIP` 不生效（IDF 原文），s3p 白开。
3. **S3 内部 DRAM 地址高于 `SOC_EXTRAM_DATA_HIGH`**，判定"不在 PSRAM"必须用区间：`!(addr >= LOW && addr < HIGH)`。
4. **`MAX_CHANNELS`**：S3=5 / C6=4；`SCHED_MAX_CHANNELS` 从它派生，不得低于物理上限。
5. **authmode 阈值保持 `WPA2_PSK`**（它是最低接受等级，天然接受 WPA3；改成 WPA2_WPA3 会拒绝纯 WPA2 AP）。
6. **任务栈/DMA/OTA 缓冲/ISR 必须内部 RAM**；flash 写（OTA/NVS）期间 cache 关闭，访问 PSRAM 会崩。
7. **`largest` 而非 `free`** 才是"需要连续块的分配"的判据。
8. **`sync_id[64]` 不能缩**：后端 `uuid.New().String()` = 36 字符；`manifest_id[32]` 可以（11 字符）。
