## 1. 目的与范围

在**本机独立部署**的一套 EHomeSystem 上，完成用户原始需求的端到端验收：

> 模拟一个带 BMS 设备的节点 → 太阳下山后关闭 BMS 充电 MOS → 太阳升起后打开 BMS 充电 MOS。

要求：前端操作（Playwright 驱动真实浏览器）+ 视觉验证（截图）+ 逐步骤留档，并据此复盘。

**范围内**：3.0 mTLS 设备传输、边缘设备（嘉佰达 BMS）创建、日出/日落规则创建（含风险动作授权）、sun_event 求值与下发、命令执行与回读校验、BMS 页面 MOS 状态呈现。

**范围外**：真实 ESP32 硬件、真实 BMS 串口链路、真实电网/电池物理回路、OTA、告警、HA 同步。

### 2.2 节点模拟器（scratch，不入库）

`backend/__scratch_simnode`（被 `.gitignore` 的 `**/__scratch_*` 覆盖）用**真实 3.0 传输**连接后端，不是 mock 后端：

- mTLS 客户端证书 CN = `sim-bms-01`（后端以 CN 作为 node_id，`transport/server.go`）；
- 12 字节 `protoframe` 头 + `pkg/frame` protobuf-lite 负载（与固件同一份实现）；
- 上行：`Hello(0x01) → ResourceReport(0x19) → StatusReport(0x02, 1s) → DataReport(0x03, 3s)`，并回执 `ConfigResult(0x05)`；
- 下行：`Ping(0x08)`→`Pong(0x09)`、`ConfigManifest(0x04)`→ConfigResult、`ChannelCmdV2(0x15)`→`Ack(0x16)+Final(0x17)`；
- BMS 侧实现嘉佰达 V19：`0x03` 读回 60 字节基本信息（`fet_status` 在 data[20]），`DD 5A E1 02 <prio> <mos>` 写帧读取软件关闭位并翻转 `fet_status` bit0/bit1，回 `DD E1 00 00 00 00 77` ACK；有界批次按固件同一信封 `[count][kind][len_le16][response]...` 回填。
- 安全红线：node_id 必须以 `sim-` 开头（与仓库仿真框架同一约束），不干扰真实设备。

## 7. 坐标选择说明（为什么不是北京）

日出与日落相差约 12 小时，同一坐标不可能在几分钟内先后发生。为在单次验证窗口内让**真实天文事件**发生，两条规则各自使用**规则级坐标覆盖**（产品已有能力，规则编辑器可填「留空=继承节点」）：

- 日落规则：纬度 35.00、经度 26.90、`Europe/Helsinki`（东地中海，当地日落 17:08）；
- 日出规则：纬度 -35.00、经度 -156.30、`Pacific/Kiritimati`（南太平洋，当地日出 05:12，UTC+14 使其落在同一北京日）。

**没有伪造系统时钟**：事件时刻由 `internal/sun` 按坐标/时区实时计算，触发由真实 ticker 驱动，截图中的墙钟时间与计算值一致。若需「同一地点」的日出+日落，只能等待真实 12 小时或注入时钟（`EvaluateClockRulesAt` 仅测试可用）。

## 11. 位置来源改为 IP / 城市（2026-11-14）

用户裁决：纬度/经度/时区只有两个来源 —— ①外网 IP 查询；②用户手动选择设备城市；
时区统一按地理位置自动填充，**不允许用户设置**。

### 11.1 实现

| 层 | 内容 |
|---|---|
| 后端 geo 包 | `internal/geo`：内置城市目录（`cities.json`，2,678 条，GeoNames cities15000 裁剪）+ IP 定位（三提供方降级/5s 超时/10 分钟缓存/代理走 `HTTPS_PROXY`） |
| 后端 API | `GET /api/v1/system/geo/ip`（503 时文案引导手动城市）、`GET /api/v1/system/geo/cities?q=&limit=` |
| 规则落库 | `automation_rules.location_source`（ip\|city）+ `location_label`（展示名）；创建/更新校验非法来源 |
| 前端 | 位置来源单选（自动定位/手动城市）；城市下拉远端搜索（默认加载人口前 20）；经纬度/时区只读展示；**删除时区输入框** |
| 校验 | 未选位置 → 「请先获取当前位置或选择设备城市（坐标与时区会自动填充）」；时区只来自定位结果 |
