## 2. 沙盒暴露的一个真实缺陷（已修）

**现象**：`node:24-alpine` 里前端 2580 条用例中 **1 条失败**：
`src/views/__tests__/MobileTableWrapper.spec.ts > 口径可复现 … AssertionError: 口径跑空（0 个文件）`

**根因**：该 spec 用 `execSync("grep -rl '<el-table' src --include=*.vue || true")` 枚举审计口径。
**BusyBox grep 不认识 `--include`**，命令失败后被 `|| true` 吞掉 ⇒ 文件数 0 ⇒ 断言红。
而本仓 `Dockerfile` 的前端构建阶段正是 `node:24-alpine` —— 任何人在容器里跑测试都会撞上；
换成 Debian（GNU grep）即全绿（B' 已证）。

**修复**：改为纯 Node 递归遍历（`readdirSync` + `<el-table` 子串判定），口径与断言一字未改；
本地 10 条用例通过，干净 alpine 全量 **2580 passed**。

> 这是"干净环境验证"的价值样本：宿主上（GNU grep + 已装 node_modules）永远绿，只有换镜像才暴露。

## 3. 干净部署冒烟（沙盒 C）细节

容器内执行（源码来自只读挂载的副本，dist 来自沙盒 B 的产物）：

1. `CGO_ENABLED=0 go build -trimpath -buildvcs=false -o /tmp/ehome-server ./cmd/server`
2. 挂载 B 的 `dist` 到 `/tmp/static`
3. 指向**全新空库** `ehome_clean_verify` 启动（`EHOME_DB_*`、`EHOME_JWT_SECRET`、`EHOME_STATIC_DIR`；无设备证书 ⇒ 设备监听自动关闭）
4. 探活：

```text
listening_after_s=1
GET /health                     → 200 {"commit":"unknown","percent":100,"phase":"ready","ready":true,"status":"ok"}
GET /                           → 200 text/html, Content-Length 1705（前端 dist 托管正常）
GET /api/v1/auth/initialization  → 200 {"code":200,"data":{"state":"uninitialized"},"message":"ok"}
服务日志：Database connected and migrated；创建分区父表 telemetry_frame / telemetry_rollup_1m
          Initialization credential (valid for 10 minutes): ...
```

即：**空库冷启动 → 自动迁移 → HTTP 就绪 → 前端可访问 → 首次运行状态正确**，全程无需宿主 Go/Node。

## 4. 复现命令

```bash
SK=/path/to/skills/devops/docker-sandbox-verify/scripts/sandbox.sh
SRC=/tmp/ehome-src   # 只放 tracked+untracked 文件（排除 .git / node_modules）
mkdir -p $SRC
{ cd /path/to/EHome && git ls-files -z; git ls-files -z --others --exclude-standard; } \
  | rsync -a --files-from=- --from0 ./ $SRC/

# A 后端（pipefail 让退出码可信）
bash $SK --image golang:1.27.3 --no-pull --src $SRC --network bridge \
  --proxy http://192.168.20.6:10808 -- env GOFLAGS=-mod=mod GOTOOLCHAIN=local \
  -- bash -c 'set -euo pipefail; cd backend; go vet ./...; go test ./... -count=1'

# B 前端（alpine 没有 bash；pnpm 必须 --prefix，容器内 /usr/local 不可写）
bash $SK --image node:24-alpine --no-pull --src $SRC --network bridge \
  --proxy http://192.168.20.6:10808 -- sh -c 'set -e; \
  npm i -g pnpm@12 --prefix /tmp/npmg --silent; export PATH=/tmp/npmg/bin:${PATH}; \
  cd frontend-shared; pnpm install --frozen-lockfile --reporter=silent; \
  pnpm build; pnpm vitest run'
```
