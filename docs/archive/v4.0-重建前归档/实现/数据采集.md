# 数据采集 — 实现

## 代码位置

### 后端
- `backend/internal/nodemgr/handler_data.go` (DataReport 接收)
- `backend/internal/nodemgr/datapipe.go` (异步管道)
- `backend/internal/worker/worker_pool.go` (异步 worker)
- `backend/internal/drivers/` (Server 侧 driver 镜像, 11 个)
- `backend/internal/models/models.go` (`UnifiedData` struct)
- `backend/internal/api/handler_data.go` (REST API)
- `backend/internal/offlinedetector/` (边缘设备级离线检测, P3 计划)

### 前端
- `frontend-shared/src/views/data/DataPanel.vue` (主面板, 794 行)
- `frontend-shared/src/components/data/RealtimeDataList.vue` (247 行, RecycleScroller)
- `frontend-shared/src/components/charts/LineChart.vue` (ECharts 按需)
- `frontend-shared/src/api/data.ts` (CRUD + 导出)

### 节点
- `esp32-collector/components/scheduler/` (定时器, 按控制器队列分发)
- `esp32-collector/components/bus_worker/` (事件驱动 RX/TX, 异步报告路径)
- `esp32-collector/components/bus_dma/` (UART/SPI/I2C 驱动层, 事件队列)
- `esp32-collector/components/bus_manager/` (总线生命周期, 控制器租约)
- `esp32-collector/components/drivers/` (ESP32 端 driver, 11 个)
  - `driver_bmp280.c/h`
  - `driver_sht30.c/h`
  - `driver_npk.c/h`
  - `driver_battery.c/h`
  - `driver_inverter.c/h`
  - 等等
- `esp32-collector/components/msg_handler/handler_data.c` (DataReport/StatusReport 编码)

## 已实现
- [x] 5 总线读物理层 (UART0/1/2, SPI, I2C)
- [x] 事件驱动 RX (UART 驱动 event queue + QueueSet, 替代 5ms 轮询)
- [x] 控制/采样队列分离 (每控制器 2 条队列, 控制保留 2 槽位)
- [x] 异步报告路径 (report_task + critical/telemetry 内存池)
- [x] 控制器租约 (bus_lease_policy, manifest 重建保持绑定)
- [x] 11 driver 解析 (Server 端 + ESP32 端)
- [x] DataReport 上报 (type=0x03, 1024B 流式缓冲区)
- [x] StatusReport 运行时性能 (field 9 runtime_perf, field 10 control_stats)
- [x] ChannelCmdV2 版本化控制 (0x15/0x16/0x17, 4 并发槽位)
- [x] 实时数据列表 (虚拟滚动 200 条)
- [x] 历史图表 (1h/24h/7d)
- [x] CSV/JSON 导出
- [x] 9 种错误码映射 (HAL)
- [x] 离线检测 (P3 计划)
- [x] host 测试覆盖 (~6000 行, bus_worker/scheduler/bus_dma/handler_data)
