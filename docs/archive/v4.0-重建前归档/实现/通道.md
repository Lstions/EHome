# 通道 — 实现

- `backend/internal/api/handler_node.go` — DMA 通道配置 API (`GET /nodes/:id/dma-channels`, `PUT /nodes/:id/dma-config`)

- `esp32-collector/components/bus_dma/` (DMA 驱动层, 5 总线实现)
