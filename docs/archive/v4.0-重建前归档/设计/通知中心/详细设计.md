# 通知中心 — 详细设计

> **版本**: v2.2
> **状态**: 已实现
> **关联**: [总体设计.md](../总体设计.md) | [00-术语表.md](../00-术语表.md)

## 1. 功能概述

通知中心统一收口业务异常 + 系统事件 + OTA 进度等, 通过 WebSocket 推前端, 顶栏铃铛 + 详情页双入口。

## 2. 数据模型

```sql
CREATE TABLE notifications (
  ID         SERIAL PRIMARY KEY,
  Level      VARCHAR(16) NOT NULL,    -- info/warning/error/critical
  Title      VARCHAR(128) NOT NULL,
  Message    TEXT,
  Source     VARCHAR(64),            -- ota/node/edge_device/...
  SourceID   VARCHAR(64),            -- 关联 ID
  Read       BOOLEAN DEFAULT false,
  CreatedAt  TIMESTAMPTZ DEFAULT NOW(),
  ExpiresAt  TIMESTAMPTZ             -- P3: 自动清理
);

CREATE INDEX idx_notifications_read ON notifications(read, created_at DESC);
CREATE INDEX idx_notifications_level ON notifications(level, created_at DESC);
```

## 4. 触发场景

| 触发 | Level | Source |
|------|-------|--------|
| 节点离线 | warning | node:{id} |
| 边缘设备 parse 错误 | error | edge_device:{id} |
| OTA 失败 | error | ota:{task_id} |
| OTA 成功 | info | ota:{task_id} |
| 登录失败 5 次 | warning | auth |
| DB 错误 | critical | system |
| 固件上传 | info | firmware:{id} |

## 5. WebSocket 推送

```
[server] 推 notification 事件
  ↓
[wsHub] 广播给所有订阅者
  ↓
[前端 wsStore] 处理
  ├─ 顶栏铃铛角标 +1 (未读)
  ├─ Popover 显示最新 5 条
  └─ 详情页追加到列表顶部
```

## 6. 容错设计

| 场景 | 行为 |
|------|------|
| WS 断连 | 自动重连 + 顶栏 NetworkBanner 提示 |
| 通知创建失败 | WARN + 不阻塞主流程 (通知是辅助功能) |
| 批量通知 (如 100 边缘设备同时离线) | 合并为 1 条摘要通知 |
| 通知过多 (>1000 未读) | 自动清理 30 天前的已读通知 |
