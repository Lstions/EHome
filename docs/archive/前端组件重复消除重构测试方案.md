## 手动验证方案（CDP 浏览器）

### 1. 硬件颜色标签一致性（P0-2）
- 打开 `/edge-device` 页面，查看解析器卡片上的硬件类型标签颜色
- 打开 `/channel` 页面，查看通道列表的硬件类型标签颜色
- **验证点**：同一硬件类型（uart/i2c/spi/gpio/adc/pwm）在两个页面颜色一致
- 预期：uart=默认, i2c=绿, spi=橙, gpio=灰, adc=红, pwm=灰

### 2. GPIO/PWM 操作守卫（P0-3）
- 打开 `/node/:id` 节点详情页
- 在 GPIO 区域：切换一个引脚电平，观察 loading 状态和反馈文本
- 在 PWM 区域：启动/停止一个通道，拖动占空比滑块
- **验证点**：操作中按钮禁用、失败时回滚、错误提示正常显示

### 3. 统计卡片（P1-1）
- 打开 `/node` 节点列表页，检查 4 张统计卡片渲染
- 打开 `/edge-device` 边缘设备页，检查 4 张统计卡片渲染
- 打开 `/config` 配置模板页，检查 4 张统计卡片渲染
- **验证点**：数值显示正确、点击跳转正常、hover 上浮效果

### 4. 历史图表（P1-2）
- 打开 BMS 设备详情页，查看电芯电压历史图表
- 切换时间范围（1h/6h/24h/自定义），确认数据刷新
- 打开通用设备详情页，查看历史数据图表
- **验证点**：batch API 正常加载、时间切换刷新、空数据显示 empty 状态

### 5. 错误页面（P1-3）
- 访问不存在的路由（如 `/nonexistent`），确认 404 页面
- 用 viewer 角色访问管理页面，确认 403 页面
- **验证点**：渐变色数字、标题、描述、按钮功能正常

### 6. 状态网格（P1-4）
- 打开 BMS 设备详情页，查看保护状态网格
- 打开逆变器设备详情页，查看告警状态网格
- **验证点**：正常/异常图标切换、标签颜色、空数据显示

### 7. 日志面板（P2）
- 打开节点详情页的日志面板
- 切换日志级别下拉框，确认 5 个选项正常
- 在历史日志标签页：测试"清理指定时间前"和"全部清理"按钮
- **验证点**：级别筛选生效、清理确认弹窗文案正确、删除后列表刷新

## 回归风险评估

| 风险项 | 等级 | 缓解措施 |
|--------|------|---------|
| useGuardedOperation 行为偏差 | 中 | 单测覆盖 GPIO/PWM Row 组件 |
| useHistoryData 降级路径 | 中 | batch 失败时自动 fallback 到逐请求 |
| StatCard 插槽兼容性 | 低 | 纯展示组件，无状态逻辑 |
| ErrorPageLayout 样式差异 | 低 | 渐变色/间距通过 props 参数化 |
| clearLogs 合并后参数传递 | 低 | 单测已验证 deleteNodeLogs 调用签名 |
