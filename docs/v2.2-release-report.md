## 已知问题

1. **EHOME_EXTERNAL_HOST**: 启动时需设置环境变量，否则 firmware 下载 URL 写入 `localhost`，ESP32 无法访问
2. **版本字符串匹配**: 服务端通过 Hello 消息自动确认 OTA 成功，当版本字符串不完全匹配时（如 `2.2.5` vs `2.2.5-fix4`）会误报 failed，实际设备已成功更新
