## 二、P1 级问题（严重的可用性/一致性缺陷）

### 禁用态与操作反馈缺失
- 节点详情"同步配置 / OTA升级 / 测延迟"呈浅蓝填充（疑似禁用因离线），**禁用态保留品牌蓝极易误点**，且无禁用原因提示（移动端尤为严重）。
- 数据面板"导出CSV"禁用无原因说明。
- 通道管理"启用状态"开关裸露在列表中，一点即切换、无确认、无状态文字，误触风险高。

### 详情页顶部操作区失控（移动端）
- 边缘设备详情 4 个按钮三种排版（右对齐/居中/居中/居中跳变），占近 1/4 屏；节点详情 3 按钮占 1/4 屏，信息区被推到首屏下半。应收敛为"更多"菜单或固定底部操作栏。
- 危险操作"删除"三种样式并存：节点列表（红色文字链接）、边缘设备列表（纯红色图标无文字）、边缘设备详情（红色描边/填充按钮），且与主操作相邻，误点风险高。

### 表单窄屏未重排
- 个人设置"确认新密码"标签折行成"确认新密/码"，"码"字与提交/重置按钮同基线碰撞（移动端高严重度）；label-input 左右布局在 375px 下输入框仅剩约 45% 宽度，应改 label-on-top。
- 仪表盘"1小时/24小时/7天"分段控件折行，"7天"掉到第二行且边框残缺（两端均出现）。

### 统计口径与数值格式化
- "今日数据 0.0k"：0 条数据被千分位格式化错误处理，应特判显示"0"（PC + 移动）。
- 统计卡"本页节点/本页在线/本页模板"口径强调"本页"，部分页无分页控件，用户无法判断与"全部"的差异；配置模板"总线类型 1/设备类型 1"语义不明（去重数还是模板数？）。
- 系统监控"采集器在线状态 0/1"的 0 用绿色，同页"采集器状态"卡离线用红色——同一事实一绿一红。

### 面包屑与页头断层
- 节点详情、边缘设备详情面包屑停留在列表级，不含当前实体名；个人设置面包屑只剩首页图标。
- 两个详情页标题策略不一致：节点详情标题用页面类型名"节点详情"，边缘设备详情用型号"prs3001"而非设备名"SN3001 Rain Gauge"。
- 移动端页头三种范式并存：通栏大标题卡（仪表盘，浪费 ~1/8 首屏）、内联标题（系统监控）、无标题（节点/边缘设备列表）。

### 空值处理混乱
- 空值表达方式并存且不一致："-"（延迟、最后数据时间）、完全空白（通信协议、硬件ID——看起来像渲染遗漏）、空白小方框（配置模板"通信协议"，疑似空 tag 渲染残留，近乎 UI 破损）、"暂无描述"、"未设置邮箱"。
- 提示缺失项但不给补救路径："未设置邮箱"无"去设置"链接，403 页"请联系管理员"无联系方式且当前账号自己就是 admin（自相矛盾）。

### 文本截断与悬字
- 边缘设备列表搜索框 placeholder"搜索边缘设备名称、类"被硬性裁切（PC）；节点列表 placeholder 以".."结尾疑似截断。
- 数据面板说明文字折行产生单字悬行"数据。"；403 页文案在"页/面"中间断行。
- 移动端设备名"SN3001 Rain Ga…"截断阈值偏保守；所属节点 ID 截断后无法辨认且无复制入口。

## 三、P2 级问题（视觉规范/打磨）

- **统计卡版式不统一（PC）**：仪表盘"标签在上/数值在下/图标居左" vs 系统监控/节点列表/边缘设备列表"数值在上/标签在下/图标居右"。应收敛为单一 StatsCard 组件。
- **筛选工具区布局不统一**：通道管理/配置模板搜索框（~200-240px）与筛选下拉（~388-552px）宽度参差；节点列表有刷新按钮、边缘设备列表没有；按钮组折行出现孤行（移动端节点列表"刷新"独占一行）。
- **语义化用色混乱**：红色用于"系统管理员"角色 tag（非告警）；404 用青绿渐变、403 用橙红渐变，均与系统扁平蓝主色无关联；"实时连接"绿色填充按钮易被误读为状态徽标，与"实时"徽标语义重叠。
- **术语中英混排无解释**："Outbox 租约中"、"未处置 UNKNOWN"、"Last Manifest / Last Sync ID"、"同步到HA"、指标枚举 "temperature"，全中文界面下缺术语表和 tooltip。
- **空状态插画对比度过低**：固件管理纸箱插画、数据面板圆形插图在白底上几乎不可见，像渲染失败的占位块。
- **顶栏状态指示语义不明（移动端）**：绿点 pill 无文字无说明；头像与下拉箭头分离成两个紧凑触控目标；视图切换图标按钮约 40px，接近 44pt 触控下限。
- **错误页细节**：404/403 内容垂直重心偏低、无品牌 logo；"返回上页"在无浏览器历史时兜底未知。
- **宽屏空间利用**：配置模板 1440px 下单列卡片右侧 70% 空白；通道管理两个筛选下拉竖排各站一行；仪表盘"异常摘要"卡 70% 空白。
- **数据自洽性钻取缺失**：异常摘要"1 离线采集器"无点击跳转入口；"采集器离线但设备在线"的组合无关联说明。

## 四、做得好的地方

- 状态色彩语义在移动端基本稳定：绿=在线/正常、红=离线/删除、黄=告警，圆角与主按钮蓝色统一，设计 token 基础尚可。
- 仪表盘趋势图空状态（说明 + "查看设备"引导按钮）是空状态最佳实践。
- 系统监控"自动刷新间隔 + 手动刷新"组合合理，指标卡层级清晰。
- 404/403 页层级清楚、主操作明确、触控目标足够，是全站最干净的页面。

## 五、修复优先级建议

1. **P0**：节点离线/同步中状态矛盾 → 边缘设备详情计数 bug → 统计卡组件窄屏布局统一重构（纵向堆叠）→ 节点详情标题破版 → 移动端表格卡片化 → 空状态收敛为单组件 → 核查 admin/观察者角色逻辑 → 重采登录页截图。
2. **P1**：禁用态规范（灰色+透明度+原因 tooltip）→ 详情页移动端操作区收敛 → 删除操作统一样式与隔离 → 表单 label-on-top 窄屏规则 → "0.0k"格式化特判 → 面包屑补当前实体 → 空值统一为"-"+离线原因。
3. **P2**：StatsCard 版式统一 → 工具栏单行规范 → 语义色规范 → 术语本地化与 tooltip → 错误页品牌与重心。
