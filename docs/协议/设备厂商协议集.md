## 1. SN-3001 光学雨量光照一体式变送器

### 1.1 串口与帧

- Modbus RTU 485，默认 4800 8N1（实机实测参数）；地址默认 0x01。
- 黄金帧已确认（读寄存器帧 + 响应帧，按实测抓包）。

### 1.2 寄存器摘要

| 寄存器 | 含义 | 备注 |
|--------|------|------|
| 0x0052 | 灵敏度 | set_rain_sensitivity 已实机闭环 |
| 0x0000 | 雨量累计清零 | reset_rainfall bounded 3 步 + readback |
| 常规读寄存器 | 雨量/光照 | read_rainfall 等 |

### 1.3 清零工作流（reset_rainfall）

bounded_sequence 三步：写清零 → 读回对账 → 终态确认（含 finally 语义）。写寄存器必须在模拟器/实机侧同步实现（0x0052 灵敏度 + 0x0000 清零写），否则 bounded 步骤无响应 FAILED。

### 1.4 实现门禁

- set_device_address / set_baud_rate：写入即切通信参数域 → 同 batch 读回不可能 → single write + ack，读回对账由 applySideEffect（配置同步 + manifest 重发 + 后续 read）跨生命周期完成。
- 实机闭环：雨量读取/清零、灵敏度/地址/波特率切换已通过真实 UART1 浏览器验证（含 NVS 重放证据）。

## 2. 泰琪丰 GB3024 逆变器通信协议（可实现摘录）

### 2.1 传输层与 CRC 门禁

- **CRC 实现门禁（阻断写操作）**：缺黄金向量则写操作不注册——这是硬门禁，不以"各类参数可写"的语义推断放行。
- 读路径经模型/协议文档摘录实现。

### 2.2 控制与查询命令表

- HSTS 模式值；HEEP1 响应与写后核对字段（原件语义冲突处按可实现摘录收敛）。
- 设置命令清单：按风险分级（只读可接入 / 写须证据）。

### 2.3 接入统一控制方案的约束

- **当前只读接入**：11 条只读 Action 可用；所有 setter 因 CRC 黄金向量缺失而冻结。
- 解冻条件：黄金向量（发送帧+期望响应含 CRC）+ 实机验证 + 写后核对字段定义齐备。
- 与嘉佰达门禁同源政策（fail-closed + 证据门禁）。

## 3. 接入新厂商协议的通用流程

1. 协议原件归档（SHA-256 留证）→ 本文件新增一节。
2. 读指令：黄金帧（真实设备抓帧）→ 驱动实现 → 实机验证 → 解锁。
3. 写指令：黄金向量 + 写后核对 + CRC/ACK 校验 → 实机验证 → 解锁（逐步，非批量）。
4. 所有门禁状态在驱动 AvailabilityCode 与本文档同步登记。
