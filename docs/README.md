## 变更清单

- **边缘设备数据生命周期管理**：逻辑设备身份（logical_device_id）、创建继承、合并且追溯、retention 可配（默认 365 天）、删除可勾选同时删数据、purge 每日任务 — [设计/边缘设备数据生命周期管理方案.md](设计/边缘设备数据生命周期管理方案.md)

### v2.7（2026-07-30）
- **多总线事件驱动与动态接口分配**：UART/SPI/I2C 动态接口分配、事件驱动 RX、独立软件队列 — [设计/多总线事件驱动与动态接口分配方案.md](设计/多总线事件驱动与动态接口分配方案.md)（✅ 已实现并合入 main）

## 术语速查

| 概念 | 正确术语 | 禁用旧名 |
|------|---------|---------|
| ESP32 设备 | **节点 (Node)** | 采集器、Collector |
| 物理传感器/执行器实例 | **边缘设备 (EdgeDevice)** | Device、设备 |
| 设备型号定义 | **设备配置 (DeviceConfig)** | 设备模板、DeviceTemplate |
| 总线通信端口 | **通道 (Channel)** | — |
| 配置下发清单 | **配置清单 (ConfigManifest)** | — |
| 写操作响应 | **WriteRsp** | — |
| 数据归属身份 | **逻辑设备身份 (LogicalDevice)** | — |

> 完整术语表: [设计/00-术语表.md](设计/00-术语表.md)
