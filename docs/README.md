## 术语速查

| 概念 | 正确术语 | 禁用旧名 |
|------|---------|---------|
| ESP32 物理设备 | **节点 (Node)** | 采集器、Collector |
| 总线通信端口 | **通道 (Channel)** | —（GPIO/PWM 不是通道） |
| 设备型号定义 | **设备配置 (DeviceConfig)** | 设备模板、DeviceTemplate |
| 物理传感器/执行器实例 | **边缘设备 (EdgeDevice)** | 设备、Device |
| 数据归属身份 | **逻辑设备 (LogicalDevice)** | — |
| 低层命令序列 | **模板 (Template)** | — |
| 受控操作协议 | **ChannelCmdV2** | WriteCommand 业务控制 |
| 配置下发清单 | **配置清单 (ConfigManifest)** | — |
