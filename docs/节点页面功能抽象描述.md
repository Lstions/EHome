# 前端「节点页面」功能抽象描述

> 用途：给 AI 重新设计节点页面时作为功能基线。
> 范围：节点列表页（/node）+ 节点详情页（/node/:id）及其所有子功能模块。
> 说明：本文件只描述"有什么功能、能做什么、交互流程、数据与业务约束"，不含任何样式/颜色/尺寸/组件实现细节，避免干扰创作。

---

## 一、节点列表页

### 1.1 统计概览
- 展示四个统计数字：本页节点总数、在线数、离线数、告警数。统计口径为当前已加载列表。
- 「总数 / 在线 / 离线」三个数字可点击，点击后相当于设置对应状态筛选；「告警」仅展示。

### 1.2 工具栏
- 关键词搜索：按节点名称/型号过滤列表；输入即过滤。
- 状态筛选：全部 / 在线 / 离线。
- 型号筛选：选项来自当前列表实际出现的型号集合。
- 视图切换：卡片视图 / 表格视图两种浏览方式，可在两种模式间切换。
- 添加节点：入口按钮（当前为占位，跳转后无实际落地功能，重设计需补齐或移除）。
- 刷新：手动强制重新拉取列表。

### 1.3 列表内容（两种视图展示同一份数据）
每个节点展示的信息：
- 名称、型号、设备ID（物理序列号）、固件版本、在线状态、连接质量、延迟、上线时间。
- 快捷操作：进入配置（占位，无落地）、发起升级（跳转固件管理页）、删除（需二次确认，删除后刷新列表）。

### 1.4 分页与筛选
- 分页（每页条数可选），列表与分页基于服务端分页，状态/型号/关键词筛选在已加载页内进行。

### 1.5 实时性与数据源
- 通过 WebSocket 接收节点状态事件：已存在的节点就地更新状态（避免整页重拉），列表中新出现的节点触发防抖的静默刷新。
- 初次进入：优先使用本地缓存渲染，无缓存时展示骨架屏；缓存有有效期，可强制刷新。
- 并发保护：多次请求只保留最新一次生效，防止旧响应覆盖新数据。

### 1.6 空状态与加载态
- 无数据时展示引导性空状态（含添加入口）。
- 加载中与加载完成后的空列表为两种不同状态，需区分。

## 二、节点详情页

### 2.1 页面导航
- 面包屑（首页 / 节点管理 / 当前节点）+ 返回按钮；标题显示节点名称，未命名时显示设备ID短码。

### 2.2 顶部操作（节点离线时全部禁用并提示原因）
- 同步配置：向节点下发配置同步命令。
- OTA 升级：打开升级对话框。
- 测延迟：下发 ping 命令，等待节点通过 WebSocket 回传延迟值后提示结果；超时提示节点可能离线。

### 2.3 基本信息
- 展示：节点名称、设备ID、型号、固件版本、状态、连接质量、延迟、上线时间、在线时长。
- 节点名称支持行内直接编辑（保存后更新列表与详情）。
- 离线时，连接质量/延迟/在线时长等实时指标显示为空态并提示无数据。
- 在线时长实时滚动（从上线时间起算到当前时刻）。

### 2.4 配置同步状态
- 展示：协议版本、最近一次下发的配置清单标识、最近同步时间、同步标识。
- 同步状态标签：已同步 / 同步中 / 落后 / 错误 / 未知；节点离线时强制显示"离线"。

### 2.5 总线配置（核心管理区）
组织方式：硬件资源管理 + 通道终端调试 两个页签。

**硬件资源管理：**
- 初始化流程：向节点下发资源查询指令 → 等待节点上报硬件资源 → 拉取用户已保存的配置 → 合并展示。
- 按总线类型（I2C / UART / SPI / ADC / GPIO / PWM）分组展示节点上报的硬件资源；每个资源展示名称、引脚、关键参数。
- 每个硬件资源下可挂载"通道"：
  - 新建通道（随硬件类型提供对应参数表单：波特率、数据位、停止位、校验、流控、从机地址、时钟频率、CS 引脚、SPI 模式、衰减、位宽等，按硬件能力动态呈现）；
  - 编辑通道（同一表单）；
  - 删除通道（需确认）；
  - 查看通道（离线时只读）。
- 保存配置：把总线启用状态与关联参数保存到节点。
- 刷新：重新拉取硬件资源与通道。
- UART 特有：修改波特率（选择通道 + 新波特率）。
- I2C / RS485-UART 特有：地址扫描（向总线发起扫描，提示发现的设备数）。
- DMA（直接内存访问）通道开关：对支持 DMA 的总线资源可开启/关闭 DMA 绑定；同一硬件一次只能绑定一个 DMA。
- GPIO 资源：可添加（配置方向：输出/输入/上拉输入/下拉输入；输出时可选初始电平；可加标签）、编辑、删除；已被总线或其他外设占用的引脚会被标记并禁止重复使用；运行态电平变化通过 WebSocket 实时刷新。
- PWM 资源：可添加（选择未占用的输出引脚、频率、占空比、分辨率、是否自动启动、标签）、编辑、删除；运行态（是否运行、实时占空比）通过 WebSocket 实时刷新。
- 所有写操作仅在线可执行。

**通道终端（底层调试工具）：**
- 实时查看指定通道总线上来回路过的数据帧（收发分别展示，可展开查看完整数据）。
- 手动发送数据：支持 HEX / ASCII 两种录入方式、可设置发送间隔与波特率。
- 终端日志可暂停/继续、导出、清空。

### 2.6 DMA 通道一览
- 只读展示节点全部 DMA 通道：名称、状态（未使用 / 已分配未绑定 / 已绑定 / 已禁用）、类型、能力、最大突发、绑定对象、兼容总线。
- 绑定/解绑操作不在此处，统一在总线配置的开关里完成；此区可刷新。

### 2.7 关联设备
- 展示该节点下挂载的所有边缘设备：名称、类型、总线地址、所在通道（可点击直达该通道的编辑）、最新一条数据（最多展示数个关键键值对：传感器名 + 数值 + 单位）、状态、最后数据时间。
- 行点击 / 「查看」进入该设备详情页。
- 刷新列表。
- 「创建设备」：打开快速创建对话框，在当前节点上直接挂载新设备（无需预先创建模板）。

### 2.8 快速创建设备对话框
- 创建流程表单：
  - 选择设备型号（解析器），型号决定数据解析方式与可用的总线类型；
  - 选择通道（仅列出与该型号总线类型匹配的节点已有通道；加载中与"无匹配通道"需区分提示，无匹配时引导先建通道）；
  - 输入设备名称；
  - 采集间隔：若所选型号的驱动声明了按指令轮询，则不填全局间隔，改为逐条指令设置轮询间隔（间隔为 0 表示禁用该指令）；驱动指令加载失败时禁止提交；
  - 「继承历史数据（可选）」折叠项：若当前设备是更换/重建的同型号设备，可选择继承旧设备的历史数据；未选择则按全新设备创建。
- 提交后创建成功刷新设备列表；关闭/取消时重置表单。

### 2.9 OTA 升级对话框
- 选择固件版本（仅可选启用中的固件，展示版本信息与当前版本对比）。
- 开始升级后展示实时进度与状态（等待 / 下载 / 安装 / 成功 / 失败），自动轮询进度。
- 升级完成前可取消。
- 成功后刷新详情中的固件版本与升级历史。

### 2.10 OTA 升级历史
- 表格展示历史记录：版本变更（旧 → 新）、状态、进度、开始时间、完成时间。
- 等待/下载中的记录可取消（需确认）。
- 可手动刷新。

### 2.11 系统日志
**控制项：**
- 日志流开关：控制节点实时日志推送的总开关。
- 日志级别选择：调整日志输出级别。
- 持久化开关：控制日志是否持久化存储；若持久化开启而日志流关闭，提示"固件不会产生日志"的警告。

**实时日志：**
- 终端式实时展示：每行 = 运行时间（固件内部运行时长，非墙钟时间）+ 级别 + 标签 + 消息。
- 数据源：WebSocket 实时推送，本地保留最近有限行数（环形缓冲）。
- 支持搜索（按标签/消息/级别过滤）、暂停滚动、清屏、导出（文本 / CSV）。
- 有未读新日志时提供"回到底部"快捷入口并显示未读数。
- 大数据量下滚动流畅（虚拟化）。

**历史日志：**
- 条件查询：时间范围、级别、标签、关键词，结果分页展示。
- 导出当前查询结果为 CSV。
- 清理：全部清理（二次确认，不可恢复）；或按"指定时间点之前"清理。
- 空结果显示空态。

### 2.12 详情页数据与交互契约
- 进入页面并行加载：节点详情、OTA 历史、DMA 通道；详情数据有缓存（短 TTL），可强制刷新。
- 设备/通道列表必须在拿到节点物理序列号后才发起查询（用路由数字ID查询会查空）。
- 节点从离线变为在线时，自动刷新总线配置与通道列表。
- WebSocket 状态事件：收到该节点的延迟回包时收尾"测延迟"流程并提示；收到其它状态变化时重新拉取详情。
- 路由参数变化（同一页面组件内切换节点）时重置全部状态并重新加载；离开页面时清理定时器、取消订阅、中止未完成请求。
- 跨会话安全：所有写操作校验会话未变更，防止登出后旧请求落地。

## 三、数据与业务约束（重设计必须遵守）

1. 节点身份双标识：数字主键（路由用）与物理序列号（数据查询用），不可混用；设备/通道/日志查询一律用序列号。
2. 离线即只读：写类操作（同步配置、OTA、测延迟、保存配置、通道增删改、GPIO/PWM 配置、DMA 开关）全部禁用并提示；读类操作不受限。
3. 二次确认操作：删除节点、删除通道、取消 OTA、清理全部/时间段历史日志。
4. 实时通道：节点状态事件（状态/延迟）驱动列表就地更新与详情刷新；日志事件驱动实时日志；外设结果事件驱动 GPIO/PWM 运行态。
5. 缓存策略：列表与详情均有短 TTL 缓存；删除节点后清空相关缓存；写操作使旧缓存失效并防止过期响应落地。
6. 必填校验：创建设备时型号、通道、名称必填；渠道无匹配时给出引导而非报错。
7. 空态覆盖：列表、关联设备、DMA、OTA 历史、实时日志（等待/无命中）、历史日志均需有对应空状态。
8. 加载态覆盖：首屏与各信息卡均有骨架/占位加载态。
9. 未落地占位功能（重设计需处理）：列表页「添加节点」跳转、卡片「配置」快捷入口当前无实际接收页面。
10. 定位区分：通道终端是底层总线调试（原始帧收发），与传感器数据展示（数据面板/设备详情）是两个不同概念，设计时不要混淆层级。
