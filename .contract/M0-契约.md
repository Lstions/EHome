## sourceref 包 API（各域按此接线，勿改签名；如需扩展先找 Lead）

```go
// 不可变快照（由 datasource 构建后推入）
type MemberSnapshot struct { MemberID, EdgeDeviceID uint; Priority int; Required bool; Status string; LastSuccess time.Time; FailCount int }
type GroupSnapshot struct {
    ID uint; Kind, Category, Combine string; MinMembers, StalenessSec int; OnDegrade string
    Enabled bool; Revision int64; TransitionSeq uint64; ActiveMemberID uint
    Members []MemberSnapshot; MembersHash string
}
func (g *GroupSnapshot) ActiveEdgeDeviceID() uint
func (g *GroupSnapshot) IsMember(edgeDeviceID uint) bool
func (g *GroupSnapshot) MemberOf(edgeDeviceID uint) (MemberSnapshot, bool)
func (g *GroupSnapshot) Staleness() time.Duration
func (g *GroupSnapshot) NormalizedOnDegrade() string
func (g *GroupSnapshot) EffectiveMinMembers() int
func SortMembers([]MemberSnapshot)
func ComputeMembersHash([]MemberSnapshot) string   // 只含 priority/required/edgeDeviceID

// 注册表（热路径无锁；唯一发布者是数据源状态机）
func NewRegistry() *Registry
func (r *Registry) ReplaceAll(gs []*GroupSnapshot)   // 启动/全量重载
func (r *Registry) Publish(g *GroupSnapshot)          // 单组 COW 替换
func (r *Registry) Remove(groupID uint)
func (r *Registry) Group(id uint) (*GroupSnapshot, bool)
func (r *Registry) Len() int
func (r *Registry) MatchFrame(edgeDeviceID uint, kind string, groupID uint) FrameMatch
type FrameMatch struct {
    GroupID uint; Kind, Category string; IsMember, IsActive bool
    Revision int64; TransitionSeq uint64; Group *GroupSnapshot
    Configured bool; Reason string
}
func (m FrameMatch) Accepts() bool   // primary_backup 只收 IsActive；composite 收任一 IsMember

// 合并（纯函数；逐分量求值后再合并）
type Component struct { MemberID, EdgeDeviceID uint; Required bool; Value float64; At time.Time; State string }
type Result struct { OK bool; Value float64; Degraded bool; Reason string; Components []Component; Revision int64; TransitionSeq uint64 }
type EvalMemberFunc func(m MemberSnapshot) Component
func CombineGroup(g *GroupSnapshot, eval EvalMemberFunc) Result
```

常量：`KindPrimaryBackup/KindComposite`、`CombineFirstAvailable/Avg/Max/Min/Sum`、`OnDegradeFailClosed/UseAvailable`、`StateOK/StateMissing/StateStale/StateNotEligible/StateNotConfigured`、`ReasonNoActive/ReasonRequiredMissing/ReasonBelowMinMembers/ReasonNoAvailableMember/ReasonActiveStale/ReasonGroupDisabled/ReasonGroupMissing`、`GroupKindSourceGroup`。

**红线**：sourceref 不得 import gorm/database/databus/notify/websocket/os/io/net（SG-18）；Combine 文件不得出现 time.Now/goroutine。

## 关键裁决（方案 v0.3，勿自行变更）

1. **按 kind 分流**：primary_backup 只收 active 成员帧；composite 收任一成员帧并整组求值。
2. **窗口身份**：primary_backup identity 含 EdgeDeviceID+Revision；composite 只含 GroupID+Revision+MembersHash（不含触发成员）。
3. **revision bump 白名单**：只拓扑/成员/priority/required/active 变更 bump；MarkSuccess/MarkFailure 运行态**不 bump**。
4. **F4 钉住触发时成员**：planner 复核必须用触发事件里的 `SourceEdgeDeviceID`，**不得**回读规则配置列；取不到 ⇒ fail-closed。
5. **禁用 cooldown=0**：source_group 规则保存期强制 `cooldown_sec >= max(成员采集间隔)`。
6. **composite 无 active**：API 对 composite 组 activate/置 active 返回 400。
7. **锚点双写**：绑来源组的规则必须同时写 `trigger_edge_device_id`（automation）/ `target_type=edge_device+target_id`（alert）= 组锚点成员（priority DESC,id ASC 首个）。
8. **失败语义**：见方案 §12.9.2 真值表；composite use_available 允许触发但必须 `Degraded=true` + 审计。
